> 远端 GitHub Issue：`#44 WBS L3: P4.1.6 统一数据层与同源快照验证`

## 工作目标

为 `P4` 建立统一的 `ToolHubStateSnapshot`，使总览、输入工具链、自演进巡检和工具仓库都从同一份状态快照投影读取数据，并通过 `snapshot_id` 验证多路数据同源。

## 工作内容

- 定义 `ToolHubStateSnapshot`、`SnapshotMeta`、`raw` 与 `derived` 边界
- 新增统一快照构建层，统一生成 `metrics / run_monitor / risk_summary / coverage_matrix / pending_suggestions`
- 统一 `overview / tools / evolution-runs` 的读接口包络
- 在前端增加三路读接口的 `snapshot_id` 一致性校验和异常提示
- 增加后端和前端自动化测试，证明不同工作区消费的是同一份状态快照投影

## 潜在难点

- 现有 `service.py` 已经承担了部分派生逻辑，迁移时要避免行为回退
- 读接口包络统一后，前端类型和现有消费方式需要同步调整
- 前端并发请求三路接口时，需要把“一致性校验”做成可见证据，而不是仅靠内部日志
