## 当前节点说明

当前 `P3` 分支已经具备独立驾驶舱页 `/xx-p3` 和最小订单闭环骨架，但按最新口径，这还不足以构成首版优先级。

这一轮最新约束是：

- `P3.1` 必须先提供不依赖订单存在的基础能力
- 这组基础能力至少包括模板展示、`PDF` 阅读器、规范查询和模板-规范映射
- `P3.2` 以后才是围绕 `需求规格说明 -> 软件设计说明 -> 批次模块工单包` 的订单流
- `软件设计说明` 仍是正式主文档，`批次模块工单包` 仍是面向 `P4` 的正式交付包
- `P3` 首版仍采用独立驾驶舱页 `/xx-p3` 作为验证与演示承载面
