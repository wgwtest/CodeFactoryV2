# 单文档处理状态图：13 阶段可直接画图节点/边清单

## 文档目的

这份文档是对 `2026-04-19-document-processing-state-graph-spec.md` 的补充。

目标不是再讲概念，而是直接回答：

1. 每个阶段图谱里哪些节点必须画出来
2. 每个阶段图谱里哪些边必须画出来
3. 哪些节点/边在运行中会动态变化
4. 默认应该高亮哪条主路径

后续无论是继续画 Pencil，还是拆前端数据结构，都可以直接以这份清单为基线。

---

## 统一约束

所有阶段图谱都必须满足以下约束：

1. 必须同时存在：
   - 主路径节点
   - 辅助上下文节点
   - 判断/风险节点
   - 结果节点
2. 主路径节点和主路径边必须明显高亮。
3. 辅助节点可以很多，但必须降噪，不得抢主路径视觉重心。
4. 节点和边都必须可点击，并进入对象观察窗。
5. 运行态下，节点和边都允许发生：
   - 新增
   - 消失
   - 断开
   - 重连
   - 状态切换
   - 聚合/拆分

## 统一画图优先级

为了保证后续继续画 Pencil 时不散，建议所有阶段都按下面的顺序构造：

1. 先画主路径节点
2. 再画主路径边
3. 再补当前阶段最关键的辅助节点
4. 再补判断/风险节点
5. 最后补静态上下文节点

如果页面空间不够，优先保留顺序始终是：

1. 主路径
2. 当前活跃节点
3. 当前活跃边
4. 风险节点
5. 结果节点
6. 其余上下文节点

## 直接用于 Pencil 的建议

如果下一步继续画 Pencil，建议：

1. 每个阶段先出一张 `运行样例`
   - 用这份文档里的“主路径 + 辅助节点 + 动态变化”来填图
2. 每个阶段再出一张 `观察窗线稿`
   - 阶段 / 节点 / 边三种视角共用统一模板
3. 不再单独出“模板页”
   - 模板规则已经固定在文档里，Pencil 页面直接画运行样例和观察窗即可
