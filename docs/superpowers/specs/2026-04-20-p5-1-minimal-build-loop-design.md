# P5.1 最小构建闭环设计

> 正式归档入口：`DOC/CODEX_DOC/02_设计说明/07A-P5.1-最小构建闭环设计.md`

> 当前文件保留为工作层过程稿。若本文件后续有被确认、被采纳或需要长期复用的修改，必须同步回 `DOC/CODEX_DOC/` 正式文档体系，尤其是 `02_设计说明/07A-P5.1-最小构建闭环设计.md` 与 `02_设计说明/07-P5-软件构建系统设计.md`。

**日期：** 2026-04-20

## 1. 节点目标

`P5.1` 只做一件事：先把 `P3 / P4 -> P5` 的最小构建闭环搭起来，让当前工作对象、当前输入绑定、当前运行态、当前输出和当前缺口能在一个独立工作台内闭合。

## 2. 节点范围

首版必须包含：

- 交付主单
- 输入绑定确认
- 装配计划
- 模拟执行器运行态
- 版本化输出目录
- 缺口与反馈留痕

首版暂不包含：

- 复杂并发调度
- 正式回流仲裁
- 页面内直接改写 `P3 / P4`

## 3. 核心功能模块

`P5.1` 的核心功能模块固定为：

1. 交付主单模块
2. 输入绑定与快照确认模块
3. 装配规划模块
4. 构建运行与服务监控模块
5. 输出导出与预览模块
6. 缺口与反馈留痕模块
7. 模拟输入适配模块

## 4. 页面区块

首版页面固定采用三栏工作台：

- 左栏：交付主单队列区
- 中栏：装配流程主视图区 + 构建运行与监控区
- 右栏：联调输入快照副区 + 输出结果预览区 + 缺口与反馈区

页面顶部只保留工作台头部条，不复用门户式全站导航。

## 5. 关键交互

### 5.1 切换交付主单

切换主单后必须同时切换：

- 当前输入绑定
- 当前装配计划
- 当前运行快照
- 当前输出预览
- 当前缺口与反馈

不允许出现“主单已经切换，但右侧仍显示上一张主单数据”的状态。

### 5.2 确认输入绑定

确认输入绑定时必须明确：

- 当前主单消费哪份冻结设计输入
- 当前主单消费哪份供给快照输入
- 新尝试是否需要冻结新的 `input_snapshot`

### 5.3 发起构建尝试

发起尝试后必须立即产生：

- 新的 `P5AssemblyAttempt`
- 新的运行快照
- 新的输出目录
- 新的缺口与反馈任务

## 6. 风格继承

阶段级工作台风格放在 `07-P5` 正式设计中固定。

`P5.1` 只继承并补充节点例外，正式口径固定为：

- 继承 `P4` 当前已被接受的轻灰画布、浅色页头、白色卡片、分段标签、莫兰迪活动态
- 不采用深色英雄区
- 不采用门户式顶部导航壳
- 只在主单选中态、运行日志区、缺口提示区和输出预览区做局部例外
