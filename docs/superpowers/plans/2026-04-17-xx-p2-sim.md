# XX-P2-Sim Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 新增 `XX-P2-Sim` 轻量需求规格说明模拟输入台，支持选择预置样板并一键提交到现有 `requirements/specs`，让 `XX-P3` 直接接收。

**Architecture:** 前端新增独立路由 `/xx-p2-sim` 和单页工作台；页面使用本地样板配置生成 `RequirementSpecWriteInput`，直接调用现有 `createRequirementSpec()`。不新增后端接口，只通过已有需求规格写入链路实现“模拟上游，真实入池”。

**Tech Stack:** React 18, TypeScript, Ant Design 5, React Router, Vitest, Testing Library
