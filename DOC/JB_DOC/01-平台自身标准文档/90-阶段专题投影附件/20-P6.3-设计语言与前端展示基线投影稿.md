# P6.3 设计语言与前端展示基线投影稿

## 1. 文档定位

**文档类别：** 标准化投影文档  
**标准依据：** 主要服务平台入口与观察层专题补充，不直接对应单一军标原件  
**当前状态：** 候选  
**主要来源文档：**

- `DOC/CODEX_DOC/02_设计说明/P6_门户与平台入口/P6.3-设计语言与前端展示基线设计.md`
- `DOC/CODEX_DOC/02_设计说明/P6_门户与平台入口/P6-门户与平台入口设计.md`

## 2. 投影目标

`P6.3` 负责统一平台级设计语言与前端展示基线。

它的职责不是让 `P1 ~ P5` 完全长成同一张脸，而是解决跨阶段观察时最容易引发理解断裂的问题：

- 名称不统一
- 状态表达不统一
- 总览条和信息卡风格不统一
- 列表、图谱、抽屉、筛选条交互语义不统一

## 3. 统一边界投影

### 3.1 必须统一的部分

- 阶段命名
- 状态文案与状态色
- 总览条与摘要卡表达
- 平台级入口按钮与跳转提示
- 抽屉、详情页、列表、图谱视图的基础交互语义
- 页面空态、加载态、错误态

### 3.2 允许保留阶段个性的部分

- 阶段特有业务字段
- 专有工作台布局
- 阶段内部图谱、建模、编排细节
- 业务特有按钮和操作链

## 4. 统一命名与状态基线

### 4.1 阶段命名

平台当前统一使用：

- `P1 业务知识库`
- `P2 需求分析系统`
- `P3 软件设计系统`
- `P4 工具仓库`
- `P5 软件构建系统`
- `P6 平台门户、观察与前端展示实验层`

### 4.2 状态文案

平台级状态文案优先使用：

- `待开始`
- `进行中`
- `已完成`
- `待人工验收`
- `阻塞中`
- `数据暂不可用`

## 5. 视觉与信息层级基线

### 5.1 视觉方向

平台级页面统一采用：

- 浅底工程蓝图方向
- 高信息密度但低视觉噪声
- 强结构感而非装饰型后台

避免：

- 大表头
- 大面积无意义留白
- 纯装饰卡片墙
- 依赖弹窗承载关键信息

### 5.2 信息层级

平台级页面的信息层级固定为：

1. 阶段身份
2. 当前状态
3. 核心指标
4. 入口动作
5. 扩展说明

## 6. 共享展示基元

`P6.3` 当前固定以下共享展示基元：

- 总览条
- 筛选与视图条
- 列表 / 图谱双视图
- 详情抽屉

这些基元用于跨阶段观察的一致表达，不替代阶段内部所有业务控件。

## 7. 当前未纳入投影的缺口声明

本投影稿当前**不补写**以下内容：

- 完整视觉 token 词典
- 组件级 API 契约
- 前端实现规范与代码约束细则

这些内容仍需在后续 `B1` 契约或实现规范层继续补足。

## 8. 当前结论

`P6.3` 当前已具备清晰的统一边界、命名基线和共享展示基元，可作为平台级展示语言专题进入 `JB_DOC`。
