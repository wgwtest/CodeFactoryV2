# 标准覆盖缺口清单

## 1. 文档定位

**文档类别：** 本地桥接文档  
**标准依据：** 无直接单一军标文种对应  
**当前状态：** 基线

本文件用于说明：在新版 `CODEX_DOC` 已显著深化的前提下，`JB_DOC` 当前已经覆盖了哪些标准化对象，仍缺哪些关键对象。

## 3. 当前仍然缺失的关键对象

### 3.1 平台自身设计层缺口

- `P5` 软件构建系统独立详细设计
- `P1 / P2 / P3 / P4` 契约级源文仍待继续补齐
- `P6.R1 / P6.R2` 仍处后置预留能力状态

### 3.2 追溯与验证闭环缺口

- 平台级 `RTVM` 的真实证据链
- `STP / STD / STR` 的平台应用样例
- 平台级发布、版本说明和移交样例

### 3.3 项目实例层缺口

- 真实项目的 `SRS` 实例
- 真实项目的 `SDD` 实例
- 真实项目的测试链实例
- 真实项目的发布与移交实例

### 3.4 编号与治理缺口

- 平台级需求编号体系
- 平台级设计编号体系
- 模板族版本规则
- `99-标准来源库/` 中旧主号页仍存在两类需长期治理的异常：
  - `DI-SESS-80858` 主号页不可稳定公开访问
  - `DI-QCIC-81794` 旧主号页本地归档错指到 ASTM 文档
- current baseline revision 证据与旧主号页状态标记，后续仍需保持同步

### 3.5 文种收敛缺口

- `10 ~ 21` 阶段 / 专题投影稿当前仍主要停留在过渡追溯层
- 平台规格说明、平台设计说明尚未完成对这些投影稿的系统性吸收
- 主文种章节与投影稿之间还缺少“已吸收 / 未吸收”的显式收敛标记

## 4. 当前风险判断

如果后续停留在“平台候选文档 + 阶段投影稿”层，而不继续下探，会出现以下风险：

- `JB_DOC` 只形成详实说明，不形成实例闭环
- `JB_DOC` 长期停留在“拆出来了，但没收回去”的过渡态
- `RTVM` 永远停留在骨架，不形成验证事实
- `P5` 长期处于边界已知但设计缺席状态
- `B1` 契约级缺口长期不落版，导致投影稿只能停留在对象和原则层
- 平台文档包标准依据虽然已经统一，但若来源库 revision 不同步，后续审阅仍会质疑其“是否真的按当前标准挂接”

## 5. 当前结论

当前 `JB_DOC` 已经完成的，不再只是“首批落架”，而是：

- 平台自身标准文档包的候选深化版

当前真正仍未完成的是：

- 阶段 / 专题投影向主文种的归并收敛
- `P5` 详细设计化
- `B1` 契约级源文落版
- 验证与发布证据化
- 项目实例样例化
