# 标准覆盖缺口清单

## 1. 文档定位

**文档类别：** 本地桥接文档  
**标准依据：** 无直接单一军标文种对应  
**当前状态：** 基线

本文件用于判断 `JB_DOC` 当前已经覆盖了哪些标准对象，尚缺哪些对象。

## 2. 当前已形成首批承接的对象

### 2.1 平台自身标准文档候选

- 平台规格说明候选
- 平台设计说明候选
- 系统工程管理计划候选
- 软件开发计划候选
- 需求追溯验证矩阵骨架
- 配置管理计划候选
- 质量保证计划候选
- 技术评审与阶段门控说明
- 验证与发布策略候选

### 2.2 产物模板中心首批对象

- 需求规格模板组
- 设计说明模板组
- `81433 / 82259` 规格模板
- `81435 / 82284` 设计模板
- `82133` 追溯矩阵模板
- `81438 / 81439 / 81440` 测试模板
- `81441 / 81442 / 81429` 发布与移交模板
- `81434 / 81436 / 81437` 接口与数据库模板

## 3. 当前仍然缺失的关键对象

### 3.1 缺正式实化的对象

- `RTVM`
  - 已有模板和平台骨架，但未形成项目级正式矩阵
- `STP / STD / STR`
  - 已有模板章节，但未形成项目级正式测试链
- `SPS / SVD / STrP`
  - 已有模板章节，但未形成项目级发布 / 交付文档
- `IRS / IDD / DBDD`
  - 已有模板章节，但未形成项目级接口 / 数据库文档

### 3.2 缺实例化验证的对象

- 任何真实项目的 `SRS` 实例
- 任何真实项目的 `SDD` 实例
- 任何真实项目的测试链实例

### 3.3 缺正式编号体系的对象

- 平台级需求编号
- 平台级设计编号
- 模板族编号与版本规则

## 4. 当前风险

如果后续只停留在“候选文档 + 模板章节”层面，而不继续向下推进，会出现两个风险：

- `JB_DOC` 只形成说明性框架，不能形成真正可用的标准副本体系
- 追溯与验证闭环无法真实建立

## 5. 当前判断

当前 `JB_DOC` 已经完成的是：

- 标准化副本文档体系的首批落架

当前 `JB_DOC` 尚未完成的是：

- 标准化实例输出体系
- 项目级追溯、测试、发布、交接文档实例化
