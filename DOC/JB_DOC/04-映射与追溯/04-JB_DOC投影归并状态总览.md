# JB_DOC 投影归并状态总览

## 1. 文档定位

**文档类别：** 本地桥接文档  
**标准依据：** 基于 `JB_DOC` 当前主文种、阶段专题投影附件、归并矩阵与缺口清单的状态汇总  
**当前状态：** 基线

本文件用于集中回答以下问题：

- `JB_DOC` 当前是否已经完成阶段 / 专题投影
- 这些投影稿是否已经归并进主文种
- 投影稿当前是主文种、附件，还是仍属过渡层
- 哪些对象已经进入“主文种 + 附件 + 追溯”闭环
- 哪些对象仍停留在 `B1 / B2` 缺口层

本文件是状态总览，不替代以下文档：

- `03-阶段专题投影归并矩阵.md`
  - 负责规定“该并到哪里去”
- `00-CODEX_DOC到JB_DOC来源映射总表.md`
  - 负责规定“来源来自哪里”
- `01-标准覆盖缺口清单.md`
  - 负责规定“还缺什么”

## 2. 当前收敛链总图

`CODEX_DOC 正式源文 -> JB_DOC 阶段 / 专题投影 -> 主文种归并矩阵 -> 主文种正文吸收 -> 附件目录化保留 -> 缺口继续追踪`

当前真实状态不是“只做了投影”，也不是“已经彻底收完”，而是：

1. `A` 类阶段 / 专题投影已经完成
2. 主文种归并规则已经落版
3. 主文种第一轮正文归并已经执行
4. 投影稿已经从主目录移入附件目录
5. `B1 / B2` 缺口仍需继续维护
