# CODEX_DOC 到 JB_DOC 来源映射总表

## 1. 文档定位

**文档类别：** 本地桥接文档  
**标准依据：** 无直接单一军标文种对应  
**当前状态：** 基线

本文件用于说明：`JB_DOC` 当前各关键文档分别吸收了哪些 `CODEX_DOC` 正式来源，以及它们当前主要承接哪些对象。

## 2. 映射原则

- 以 `CODEX_DOC` 为研发权威根
- `JB_DOC` 允许多来源合成，不追求逐文件复制
- 只有正式文档层内容，才作为 `JB_DOC` 的稳定来源
- `superpowers` 草稿若已被回写进 `CODEX_DOC`，则通过 `CODEX_DOC` 间接进入 `JB_DOC`
