Overview
Title:  Software Test Description (STD)
Scope:  The Software Test Description (STD) describes the test preparations, test cases, and test procedures to be used to perform qualification testing of a Computer Software Configuration Item (CSCI) or a software system or subsystem. The STD enables the acquirer to assess the adequacy of the qualification testing to be performed.
