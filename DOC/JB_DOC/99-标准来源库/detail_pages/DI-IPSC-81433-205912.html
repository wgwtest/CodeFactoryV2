Overview
Title:  Software Requirements Specification (SRS)
Scope:  The Software Requirements Specifications (SRS) specifies the requirements for a Computer Software Configuration Item (CSCI) and the methods to be used to ensure that each requirement has been met. Requirements pertaining to the CSCI's external interfaces may be presented in the SRS or in one or more Interface Requirements Specifications (IRSs) (DI-IPSC-81434A) referenced from the SRS.
