Overview
Title:  Software/Hardware Requirements Specification (SHRS)
Scope:  The Software/Hardware Requirements Specification (SHRS) specifies the requirements for a system/subsystem(s), Computer Software/Firmware Configuration Item (CSCI), Computer Software Components (CSCs) and the methods to be used to ensure that each requirement has been met. Requirements pertaining to the external interfaces may be presented in the SHRS or in one or more Interface Requirements Specifications (IRSs) (DI-IPSC-81434A) referenced from the SHRS.
