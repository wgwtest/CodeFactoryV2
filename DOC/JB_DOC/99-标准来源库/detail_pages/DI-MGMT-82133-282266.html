Overview
Title:  Requirements Traceability Verification Matrix (RTVM)
Scope:  The Requirements Traceability Verification Matrix (RTVM) provides bidirectional traceability from high-level system performance requirements, to the lowest-level requirements. The RTVM shows the traceability and allocation of the requirements contained in the specification tree (i.e. performance specification, detailed specification, subsystem specification, software requirements specification, interface specification and design documentation). The RTVM is also used to verify how each requirement is verified.
