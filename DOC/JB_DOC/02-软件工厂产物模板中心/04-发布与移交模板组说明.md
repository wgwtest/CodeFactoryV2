# 发布与移交模板组说明

## 1. 文档定位

**文档类别：** 标准文种候选文档  
**标准依据：**

- `DI-IPSC-81441 Software Product Specification`
- `DI-IPSC-81442 Software Version Description`
- `DI-IPSC-81429 Software Transition Plan`

**当前状态：** 骨架

## 2. 模板组目标

本模板组用于补齐软件工厂的发布、版本和移交流程表达。

## 3. 模板组组成

- `SPS`
  - 软件产品规格
- `SVD`
  - 软件版本说明
- `STrP`
  - 软件过渡 / 移交计划

## 4. 当前为什么重要

没有这一组模板，就难以形成：

- 正式发布基线
- 版本差异表达
- 交付与移交边界说明

## 5. 当前状态说明

当前这组模板为后续补齐对象，尚未进入主线实现，但已纳入路线图。
