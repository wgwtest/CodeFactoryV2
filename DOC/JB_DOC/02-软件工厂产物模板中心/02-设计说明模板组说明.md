# 设计说明模板组说明

## 1. 文档定位

**文档类别：** 标准文种候选文档  
**标准依据：**

- `DI-IPSC-81435 Software Design Description`
- `DI-IPSC-82284 Software/Hardware Design Description`

**当前状态：** 基线

## 2. 模板组目标

本模板组用于说明软件工厂在设计编制阶段形成正式设计说明时，应如何选择标准模板。

## 3. 当前模板分流规则

### 3.1 软件级对象

当对象为软件级应用或服务时，优先采用：

- `81435`

### 3.2 平台级 / 系统级对象

当对象边界达到平台、系统或子系统层级时，优先采用：

- `82284`

## 4. 对应 `P3` 的关系

`P3` 当前输出存在三层：

- 内部权威层：结构化设计基线
- 文档投影层：软件设计说明
- 交接投影层：批次模块工单包

其中，与本模板组直接对应的是：

- 文档投影层

## 5. 当前应覆盖的最小章节

### 5.1 软件级模板最小章节

- 范围
- 设计决策
- 架构设计
- 详细设计
- 追溯

### 5.2 平台级模板最小章节

- 范围
- 总体概述
- 架构设计
- 接口设计
- 详细设计
- 追溯

## 6. 当前结论

设计说明模板组是软件工厂当前最关键的主链模板中心之一，后续应持续与 `P3` 的生成逻辑同步演进。
