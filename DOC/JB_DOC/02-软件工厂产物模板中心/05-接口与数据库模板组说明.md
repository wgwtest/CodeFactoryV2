# 接口与数据库模板组说明

## 1. 文档定位

**文档类别：** 标准文种候选文档  
**标准依据：**

- `DI-IPSC-81434 Interface Requirements Specification`
- `DI-IPSC-81436 Interface Design Description`
- `DI-IPSC-81437 Database Design Description`

**当前状态：** 骨架

## 2. 模板组目标

本模板组用于承接软件工厂在后续扩展中，对接口和数据库类交付对象的标准化表达。

## 3. 模板组组成

- `IRS`
  - 接口需求规格
- `IDD`
  - 接口设计说明
- `DBDD`
  - 数据库设计说明

## 4. 当前适用场景

当后续生成对象出现以下情况时，应优先考虑引入本组模板：

- 跨系统对接较复杂
- 数据结构与数据库设计成为重点
- 单独的接口契约需要独立交付

## 5. 当前状态说明

当前本组模板尚未纳入主线实施，但应保留为模板中心的标准扩展位。
