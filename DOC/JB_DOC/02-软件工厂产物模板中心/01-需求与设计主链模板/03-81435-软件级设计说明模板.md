# 81435 软件级设计说明模板

## 1. 文档定位

**文档类别：** 标准文种模板  
**标准依据：** `DI-IPSC-81435 Software Design Description`  
**当前状态：** 基线

## 2. 适用对象

适用于：

- 软件级应用
- 软件服务
- 明确的软件产品对象

## 3. 模板章节

### 3.1 范围

- 设计对象
- 输入基线
- 设计目标

### 3.2 设计决策

- 关键约束
- 技术取舍
- 架构原则

### 3.3 架构设计

- 模块划分
- 控制流
- 数据流

### 3.4 详细设计

- 模块职责
- 输入输出
- 数据结构
- 异常与约束

### 3.5 需求追溯

- 需求到设计的映射

## 4. 与软件工厂主链的关系

- 来源：`P3` 的结构化设计基线
- 去向：人工评审、冻结与后续工单化
