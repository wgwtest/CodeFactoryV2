# 软件工厂产物模板中心总说明

## 1. 文档定位

**文档类别：** 标准化辅助文档  
**标准依据：** 汇总 `81433 / 81435 / 82259 / 82284` 及后续扩展文种  
**当前状态：** 基线

本目录用于说明软件工厂未来生成标准化交付物时所依赖的模板中心，不直接承接具体项目实例。

## 2. 模板中心的职责

模板中心负责：

- 组织需求、设计、测试、发布、接口与数据库等模板族
- 说明不同标准对象的适用范围
- 规定对象选择规则
- 为后续实例项目生成正式交付文档提供基础模板约束

## 3. 模板中心不承担的职责

- 不替代平台研发文档
- 不替代某个实例项目的正式交付目录
- 不负责保存研发过程记录

## 4. 当前模板中心分组

- 需求规格模板组
- 设计说明模板组
- 测试文档模板组
- 发布与移交模板组
- 接口与数据库模板组
- 后续待补模板清单

当前已落地的模板目录包括：

- `01-需求与设计主链模板/`
- `02-验证与交付模板/`
- `03-接口与数据库模板/`

其中需求规格模板资产在 `01-需求与设计主链模板/01-需求规格模板/` 下按性质拆分：

- `基础模板/`：保存 `81433`、`82259` 等标准基础模板依据，只读、受控维护，用于创建模板实例和追溯标准来源。
- `自定义模板/`：保存基于基础模板派生的可编辑模板实例，采用 `manifest.json` 保存实例元数据，采用 Markdown 文件保存实例正文。

基础模板不进入 Lab 的可编辑实例列表，不能在 Lab 主界面直接修改或删除。Lab 可以把成熟的自定义模板实例“保存为基础模板”，但该动作只能追加生成新的基础模板依据和基础模板 manifest 记录，不能覆盖既有 `81433`、`82259` 等基础依据。

模板中心承接模板资产，不承接项目交付样例。未来某个项目生成出的需求规格说明、设计说明或测试文档样例，应放入 `03-项目实例与样例/`，不得与模板资产混放。

## 5. 当前优先级

当前模板中心优先级遵循：

- 先巩固 `P2 / P3` 主链模板
- 再补齐追溯与测试链
- 最后扩展接口、数据库、发布与移交链
