# 软件工厂产物模板中心总说明

## 1. 文档定位

**文档类别：** 标准化辅助文档  
**标准依据：** 汇总 `81433 / 81435 / 82259 / 82284` 及后续扩展文种  
**当前状态：** 基线

本目录用于说明软件工厂未来生成标准化交付物时所依赖的模板中心，不直接承接具体项目实例。

## 2. 模板中心的职责

模板中心负责：

- 组织需求、设计、测试、发布、接口与数据库等模板族
- 说明不同标准对象的适用范围
- 规定对象选择规则
- 为后续实例项目生成正式交付文档提供基础模板约束

## 3. 模板中心不承担的职责

- 不替代平台研发文档
- 不替代某个实例项目的正式交付目录
- 不负责保存研发过程记录

## 4. 当前模板中心分组

- 需求规格模板组
- 设计说明模板组
- 测试文档模板组
- 发布与移交模板组
- 接口与数据库模板组
- 后续待补模板清单

当前已落地的模板目录包括：

- `01-需求与设计主链模板/`
- `02-验证与交付模板/`
- `03-接口与数据库模板/`

## 5. 当前优先级

当前模板中心优先级遵循：

- 先巩固 `P2 / P3` 主链模板
- 再补齐追溯与测试链
- 最后扩展接口、数据库、发布与移交链
