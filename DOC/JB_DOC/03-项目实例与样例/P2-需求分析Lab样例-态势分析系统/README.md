# P2 需求分析 Lab 样例-态势分析系统

## 1. 目录定位

本目录用于存放 P2 需求分析 Lab 的态势分析系统样例文档。该目录不是模板目录，不替代 `DOC/JB_DOC/02-软件工厂产物模板中心/` 中的需求规格模板。

## 2. 文档清单

- `01-需求规格说明样例-态势分析系统.md`：完整样例答案，仅供人工评估、对照复核和后续设计参考。
- `02-动态考官手册-态势分析系统.md`：面向 Codex 或人工测试者的受控动态交互策略，以回答组织器问题为主，不规定固定投喂轮次。
- `03-组织器评估清单-态势分析系统.md`：用于检查组织器最终产物是否覆盖关键需求域。

## 3. 使用边界

- 不得把完整样例一次性输入给被测组织器。
- 不得把本目录样例误登记为需求规格模板。
- 允许测试者根据组织器当前问题和输出，动态选择少量事实进行补充、纠偏或追问。
- 评估重点是组织器是否能通过交互识别角色、流程、功能、数据、边界、非功能和验收准则。
