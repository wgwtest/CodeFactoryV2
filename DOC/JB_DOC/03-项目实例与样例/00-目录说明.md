# 项目实例与样例目录说明

## 1. 文档定位

**文档类别：** 标准化辅助文档  
**标准依据：** 无直接单一军标文种对应  
**当前状态：** 生效

本目录用于承接未来具体项目实例的标准化输出样例。

## 2. 当前职责

当前阶段本目录只做占位说明，不承接真实项目实例。

## 3. 后续使用方式

未来每个实例项目建议单独建目录，例如：

- `01-某项目样例/`
- `02-某项目样例/`

每个项目样例目录中可按实际需要放入：

- 需求规格实例
- 设计说明实例
- 测试文档实例
- 发布与移交实例

## 4. 当前原则

- 实例文档不应与模板文档混放
- 需求规格基础模板和自定义模板实例统一放入 `DOC/JB_DOC/02-软件工厂产物模板中心/`，不放入本目录
- 实例文档必须注明所使用的模板来源
- 实例文档应与 `JB_DOC/04-映射与追溯/` 建立回链
