## 2. 本轮修正依据

用户指出：

1. P1 下方挂载的小圆点已经表达知识正在入库，再画 `外部知识入库 23 条/分钟` 箭头不合理。
2. 数据应该能被看见从一个输出向另一个输入流动或涌动，可以使用小标签或小点。
3. 缺少 `P3 -> P5` 的箭头。

v17 因此把 P1 的外部输入表达交给底部挂载队列；阶段间流动通过连线粒子和小对象标签表达；新增 P3 到 P5 的设计基线流。
