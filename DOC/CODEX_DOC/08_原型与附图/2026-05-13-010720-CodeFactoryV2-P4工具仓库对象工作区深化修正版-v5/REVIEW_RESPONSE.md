# P4 v4 用户批注处理说明

## 1. 批注结论

用户对 `P4 六对象入口修正版 v4` 的批注成立。

v4 虽然把 6 个左侧入口拆成了 6 张图，但工作区仍存在明显问题：

- `6.1` 右栏使用泛化指标，没有解释当前选中工单是什么，也没有形成“进入工单”的清晰动作。
- `6.3` 工具资产资源列表仍然像三列平铺，不像资产大页内的子 Tab。
- `6.4` 单工具资产属性没有充分体现“成品工具”的使用工程、版本变化和演进关系。
- `6.5` 演进行为动作没有表达演进配置、轮次、涉及工具数量和影响面。
- `6.6` 被演进对象轨迹缺少图形化表达，应使用类似 GitHub 分支图的版本主干、演进分支和回退点。
- 各工作区右上角按钮存在为填充而添加的问题，业务动作不够严谨。

## 2. 本版修正方式

v5 不覆盖 v4，另建正式原型版本包。

v5 的主要修正如下：

| 入口 | v5 修正 |
| --- | --- |
| 需求工单列表 | 右栏改为当前选中工单详情，解释工单是什么，并只保留 `进入工单` 主动作 |
| 单工具需求配置 | 保留匹配、验证、审定、制造状态，但明确这是进入工单后的单小工具需求配置页 |
| 工具资产大页 | 改为资产大页内部子 Tab：`资源列表`、`覆盖矩阵`、`验证队列`、`取用接口` |
| 成品工具属性 | 强调成品工具用在哪些工程中、版本如何变化、如何被演进和回退 |
| 演进配置运行 | 改为演进配置、触发策略、轮次、涉及工具数量、发现项和影响面的工作区 |
| 演进分支轨迹 | 改为分支轨迹图，表达版本主干、演进分支、合入点和回退点 |

## 3. 对 v4 的处理

v4 保留为过程版本，不再作为当前推荐评审入口。

当前推荐用户评审 v5。
