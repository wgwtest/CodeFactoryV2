4. 总体架构
4.1 架构原则

系统采用统一工作台入口，围绕规划任务、冲突识别、协同确认和审计追溯形成服务边界。

4.2 模块划分

规划任务管理负责创建、编辑、发布和归档规划任务，并向冲突识别、协同确认模块提供任务上下文。

5.1 规划任务服务

规划任务服务需要暴露任务草稿保存、任务提交校核、任务版本记录和协同状态查询能力。

6.1 追溯关系

模块与需求条款 REQ-3.2、REQ-4.1 保持追溯；待确认项进入评审检查。
