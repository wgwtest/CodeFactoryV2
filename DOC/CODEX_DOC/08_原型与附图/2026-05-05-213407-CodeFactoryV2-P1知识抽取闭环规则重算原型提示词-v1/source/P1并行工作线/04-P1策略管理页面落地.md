# P1 并行工作线 04：P1 策略管理页面落地

更新时间：2026-05-06

## 工作目标

把用户负责范围内的 P1 页面按新 UI 原型落地。重点是策略管理、文档接入、抽取启动、规则合同、版本差异和影响面重算这些“抽取闭环控制台”页面。

这条线不是深挖后端规则执行算法，而是让页面结构、入口、数据绑定、用户路径清楚可用。

## 工作边界

负责内容：

- P1 页面路由与入口。
- 页面布局按原型调整。
- 策略库选择、复制、新建、设为默认。
- 阶段策略配置表单。
- 规则字段合同编辑入口。
- 版本差异查看入口。

- API 暂缺时使用清晰的 mock fallback 或空状态提示。
- 前端测试覆盖关键交互。

不负责内容：

- 不改发布治理和发布态知识图谱。
- 不重写后端策略算法。
- 不负责 runtime stream 事件设计。
- 不负责单文档图谱复杂交互。
- 不主动提交或推送 Git，由主线程统一收口。

## 页面实现要求

知识库总览与抽取启动页：

- 当前知识库选择。
- 策略库入口。
- 创建知识库。
- 知识库列表。
- 当前知识库运行总览。
- 策略与质量摘要。
- 启动抽取确认弹窗。
- 规则变更提醒和影响面入口。

文档清单与文档选择页：

- 文档状态筛选。
- 抽取状态筛选。
- 策略包筛选。
- stale 对象筛选。
- 表格批量选择。
- 右侧文档详情。
- 进入实时抽取工作台入口。
- 选择或更换策略入口。

文档接入与解析验证页：

- 上传与解析队列。
- 解析结果预览。
- 解析质量与入库准备。
- 知识内容类型选择。
- 推荐策略。
- 生成统一文档预览。
- 送入知识库抽取。

策略库与策略模板管理页：

- 策略包分类。
- 策略包资产库。
- 策略包详情。
- 使用策略弹窗。
- 复制、改造、设为默认。

阶段策略配置页：

- 13 阶段导航。
- 当前阶段配置表单。
- 输入输出关系图。
- 规则列表。
- 策略预览与影响提示。
- 保存为新版本。

规则字段合同编辑页：

- 输入字段合同。
- 输出字段合同。
- 判断条件。
- 动作映射。
- 合同完整性检查。
- RuleExecutionRecord 预览。
- 保存草稿或保存为新版本。

版本差异与影响面：

- 策略版本差异。
- 规则差异列表。
- 差异解释窗。
- 生成影响面。
- 增量重算任务状态。

- 用户可以从知识库总览进入文档清单、策略库、阶段策略配置。

- 阶段策略配置可以进入规则字段合同编辑。
