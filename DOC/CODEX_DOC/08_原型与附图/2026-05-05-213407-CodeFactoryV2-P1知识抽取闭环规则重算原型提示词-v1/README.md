# CodeFactoryV2 P1 知识抽取闭环与规则重算原型提示词 v1

## 1. 版本定位

本原型包用于整理 `P1 / P0` 当前负责范围内的页面设计输入，重点覆盖：

- 知识库创建、文档导入、抽取启动与单文档实时抽取。
- 13 阶段知识生成链路的运行态展示。
- 策略库/策略模板复用、阶段策略配置、规则输入输出合同、策略版本快照。
- 规则变更后的影响面计算、增量重算、知识内容动态调整。
- 质量门禁、发布候选快照、治理确认边界。

本包不是最终 UI 图，也不是前端实现代码；它是一组可交给专业 UI 生成模型的页面原型提示词。

## 4. 文件说明

- `source/01-P1知识抽取闭环页面清单与UI原型提示词.md`：完整页面清单、全局设计约束、每个页面的 UI 生成提示词。
- `source/14-规则字段配置与合同编辑页.md`：新增的单页提示词，专门用于生成字段级规则配置与合同编辑 UI。
- `REVIEW_RESPONSE.md`：已收录评审图的结论、可作为开发依据的部分和开发时需要修正的边界。
- `original/`：用于后续存放参考图、历史截图或用户确认过的视觉材料；其中旧版 `candidate-10-*` 与 `candidate-11-*` 仅作为被替换的结构参考，因视觉风格与 01-09 不一致，不作为主开发方向稿。

## 5. 使用建议

将 `source/01-P1知识抽取闭环页面清单与UI原型提示词.md` 中每个页面的“UI 生成提示词”单独复制给 UI 生成模型。建议每次只生成一个页面，先确认信息架构和视觉语言，再统一收敛全局导航、状态颜色和图谱表达。
