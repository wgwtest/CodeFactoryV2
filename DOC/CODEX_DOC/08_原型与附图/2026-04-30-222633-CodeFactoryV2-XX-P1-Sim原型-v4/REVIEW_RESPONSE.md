# v3 评审响应

## 用户批注

用户主要认可 v3 的 `5.2 P2 选择 P1 领域知识` 和 `5.3 P2 普通编辑态`，但指出 `5.1 XX-P1-Sim 模拟输入台` 有四个问题：

1. 注册相关卡片含义不清，用户看不懂这些状态到底在做什么。
2. 接口区命名过于抽象，本质上就是服务接口。
3. 如果服务接口和调用日志重要，就不应放在右侧弱区域，应放在更核心的位置。
4. 左侧看起来像 Tab 或导航，但无法判断点击后是否会切换页面，容易误导。

## 判断

批注成立。

`XX-P1-Sim` 的核心不是展示一组抽象服务状态，而是让人直观看到：这是一个模拟 P1 上游知识服务的接口台，P2 会通过它读取领域知识。接口和调用日志是联调时最关键的对象，应在 5.1 第一屏主工作区正面呈现。左侧如果没有真实切换能力，就不应做成类似 Tab / 导航的样式。

## v4 处理

1. 删除 v3 中语义不清的注册总览卡片。
2. 将接口区域直接命名为 `P1 服务接口`。
3. 将 `P1 服务接口` 与 `最近调用日志` 放到 5.1 主工作区第一行。
4. 左侧改为静态服务摘要，只展示连接状态、服务标识、领域知识数量、知识版本和最近调用数量。
5. `领域知识目录` 与 `知识包预览` 保持为下方主区内容，继续表达 Sim 只提供领域知识，不提供目标软件目录。
6. 5.2 和 5.3 沿用 v3 结构，只随 v4 统一重新截图。
