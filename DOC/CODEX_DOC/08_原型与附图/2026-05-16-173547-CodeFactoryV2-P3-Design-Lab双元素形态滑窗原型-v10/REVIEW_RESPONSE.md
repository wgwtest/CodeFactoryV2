# v10 评审响应记录

## 1. 来源

用户对 v9 的主要批注：

- 主工作区顶部“软设工作区形态传递链总览、上一段、下一段、定位选中对象”没有意义。
- 滑窗概念没有直观体现当前窗口涵盖哪几个段落。
- 一个页面展示三种形态过多，缺少编辑可能性。
- 当前选中对象放在底部窄条不适合操作，应放到右侧 Inspector。

## 2. 处理结果

| 批注 | v10 处理 |
| --- | --- |
| 删除无意义顶部标题动作行 | 工作区内部上来就是形态滑窗条，不再有“上一段 / 下一段 / 定位选中对象” |
| 滑窗要显示当前覆盖哪两段 | 顶部蓝色框覆盖当前两个相邻形态，并在右上角显示 `当前：A -> B` |
| 三个形态太多 | 主体改为双元素窗口，每张图只显示两个相邻形态 |
| 底部选中对象无操作空间 | 当前对象、追溯链、检查项和动作统一放入右侧 Inspector |
| 需要把需规也纳入链条 | 第一张图从 `需规 -> 软设文档` 开始 |

## 3. 仍待用户确认

- 双元素窗口是否比 v9 三元素窗口更符合实际编辑需求。
- 右侧 Inspector 的信息密度是否合适。
- 顶部滑窗条当前是分段窗口，后续是否需要进一步设计成真实可拖动条。
