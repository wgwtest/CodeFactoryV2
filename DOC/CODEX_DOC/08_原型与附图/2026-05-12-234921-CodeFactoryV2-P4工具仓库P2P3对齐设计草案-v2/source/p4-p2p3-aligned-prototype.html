运行事实与投影刷新说明

1. 命令事实

用户在需求工序中审定制造，后端写入审定事实和制造任务。前端不直接推进长耗时任务。

2. Runtime 事实

运行协调器领取任务、推进进度、登记工具资产，并把制造结果写回工具仓库事实层。

3. 查询投影

Overview、Tool List、Demand Progress 和 P5 Query 读投影。刷新投影是运行链的一部分，不是 UI 临时拼接。
