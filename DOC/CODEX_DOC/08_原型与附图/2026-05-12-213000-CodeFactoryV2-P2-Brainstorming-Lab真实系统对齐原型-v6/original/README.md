## 3. 用途

这些截图不是最终评审图，而是 v6 原型的事实源。v6 正式评审图位于版本包根目录。

本目录截图用于证明：

1. 当前真实 Lab 已经不是简单配置页。
2. 配置页包含组织器插件、Provider、模板实例和 Markdown 编辑器。
3. 会话页包含 CLI 问答和四个过程产物子视图。
4. 当前 Turn 与调用日志已经是复杂审计视图。
5. v6 原型应当对齐真实运行系统，而不是继续扩展 v5 的事项中心想象。
