# v16 评审响应说明

## 1. 用户批注

用户指出 v15 的三个直观问题：

1. 每个卡片的输入输出不应做成夸张标签，只需要小圆圈、亮暗圆圈或可吸附节点样式。
2. 顶部用户表达不应错落排布，应整齐对齐。
3. v15 没有认真参考用户点名认可的浅色卡片参考图；该图仍在主目录中，应纳入参考。

## 2. 判断

三条批注均成立。

v15 的卡片端口虽然语义正确，但视觉权重过高，像额外业务标签，破坏了卡片本体的清爽度。顶部用户积木做了错落变化，和用户想要的“整齐动态接入用户”不一致。v15 也没有把主目录中的浅色参考图作为原始材料落入版本包，导致设计依据不够直观。

## 3. v16 修正

| 批注点 | v16 修正 |
| --- | --- |
| 端口标签过重 | 卡片左右端口改为 `20 x 20` 小圆形吸附节点；端口文字在视觉上隐藏，只保留 DOM 辅助语义 |
| 用户不对齐 | 顶部用户积木统一水平居中对齐，取消错落位移 |
| 浅色参考图未纳入 | 复制主目录参考图到 `original/用户点名浅色卡片参考图.png`，README 写明其设计影响 |
| 卡片气质偏硬 | 卡片边框、阴影、分区背景改得更接近参考图的浅色轻量层级 |

## 4. 保持不变

1. 五阶段主链不变：`P1 -> P2 -> P3 -> P4 -> P5 -> 交付目录`。
2. P1 只向 P2 输出知识，不增加额外下游。
3. 不恢复独立行业用户卡。
4. 不把 P6 画成 P1-P5 的输出接口。
5. 不覆盖 v15、v12 或 v14。
