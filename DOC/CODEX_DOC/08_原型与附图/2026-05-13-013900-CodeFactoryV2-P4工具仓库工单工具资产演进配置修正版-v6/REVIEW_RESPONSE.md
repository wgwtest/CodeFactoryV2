# P4 v5 用户批注处理说明

## 1. 批注结论

用户对 `P4 对象工作区深化修正版 v5` 的批注成立。

v5 仍然不够细：

- `6.1` 应是 `工单池 -> 工单 -> 工具` 三层递进，不只是工单列表和工具清单。
- `6.2` 的可操作内容应偏向 `匹配策略 / 交付约束 / 版本控制`。
- `6.3` 工具资产大页应体现多种展示形态，不该只落在资源列表。
- `6.5` 演进配置需要更完整的控制项和统计口径。

## 2. 本版修正方式

v6 不覆盖 v5，另建正式原型版本包。

| 入口 | v6 修正 |
| --- | --- |
| 6.1 工单池、工单与工具递进 | 明确三层递进：工单池、工单、工具；`进入工单` 放在当前工单说明内 |
| 6.2 单工具匹配策略交付约束版本控制 | 用当前工具简介、匹配策略、交付约束和版本控制代替浅表状态链 |
| 6.3 工具资产四种展示形态 | 明确四种展示形态：资源列表、覆盖矩阵、验证队列、取用记录 |
| 6.5 演进配置深化 | 增补回合上限、回退边界、人工边界、自动策略和统计口径 |

## 3. 对 v5 的处理

v5 保留为过程版本，不再作为当前推荐评审入口。

当前推荐用户评审 v6。
