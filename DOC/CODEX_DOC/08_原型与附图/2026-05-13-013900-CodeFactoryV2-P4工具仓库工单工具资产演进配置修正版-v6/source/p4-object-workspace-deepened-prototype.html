与 6.1 的区别

6.1 是选工单；这里是当前工具的匹配策略、交付约束和版本控制，不只是状态链。

匹配策略 / 交付约束 / 版本控制

匹配策略

优先匹配可复用航路约束校验器；如果路径规划输出要求更复杂，则进入制造候选。

交付约束

交付前必须带 schema、样例和 P5 消费说明；缺少任一项不允许标记为可取用。

版本控制

同一工具只允许保留一个 active 主版本；补丁版本可并行存在，但需要明确回退点。
