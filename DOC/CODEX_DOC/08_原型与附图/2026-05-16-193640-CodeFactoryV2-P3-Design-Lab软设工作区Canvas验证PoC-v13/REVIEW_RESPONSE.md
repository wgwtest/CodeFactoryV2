# v13 评审响应记录

## 1. 来源

用户提出：

- v12 原型组织形态可接受。
- 软设工作区是丰富场景编辑，不适合继续用传统 DIV 强排版。
- 希望基于 Canvas 做验证性实现。
- 验证实现不要并入主工程和主目录。
- 先补齐拖拽、缩放、滑窗切换、动态文字布局等能力，再决定是否并入正式设计。

## 2. 处理结果

| 要求 | v13 处理 |
| --- | --- |
| 不并入主工程 | 放在 `DOC/CODEX_DOC/08_原型与附图/...v13/`，独立 HTML |
| 顶部滑窗用 Canvas | `trackCanvas` 绘制滑窗轴和当前窗口框 |
| 主工作区用 Canvas | `mainCanvas` 绘制完整软设形态长卷 |
| 支持拖拽 | 主画布支持鼠标拖拽平移 |
| 支持缩放 | 主画布支持滚轮缩放 |
| 大型对象验证 | 分层架构对象故意放大到 `1180 x 820` |
| 文字动态布局 | 使用 Canvas `measureText` 做中文折行并缓存 |
| 选中联动 | 点击 Canvas 对象后更新右侧 Inspector |
| 自检 | Playwright 截图 + 自动交互脚本验证通过 |

## 3. 仍待用户确认

- Canvas 长卷交互方向是否符合预期。
- 顶部滑窗轴和主画布都 Canvas 化的策略是否接受。
- 正式实现时优先评估 `react-konva`，还是继续走自研 Canvas 2D。
