# P4 上一轮用户批注处理说明

## 1. 批注结论

用户对上一轮 `P4 工具仓库` 原型的批注成立。

本轮关键澄清是：用户不要求重构原型主体结构，而是要求在现有界面体系下调整每个页面的内容表达，并额外增加 `工单处理` Tab 页面。

## 2. 本版修正方式

v8 另建正式原型版本包。前序 P4 原型包已按用户要求清理，当前正式评审入口只保留 v8。

| 批注点 | v8 修正 |
| --- | --- |
| 工单处理需要独立页面 | 在工单池后新增 `工单处理` 页面，展示工单生命周期和工单内所有工具进展 |
| 原 `单工具匹配策略` 命名不准 | 改为 `工具构建`，强调匹配 + 生产 + 实时过程值 |
| 工具生产过程不可见 | 增加匹配置信度、生产进度、过程事件、输入 schema、约束编译、样例生成、交付投影 |
| 覆盖矩阵不合适 | 改为 `覆盖知识图谱`，表达业务变化、时序变化和覆盖关系 |
| 验证队列无用 | 删除验证队列评审图 |
| 取用记录要前置 | 改为 `取用驾驶舱`，展示热点工具、冷门工具、热点领域、冷门领域和动态取用事件 |

## 3. 对前序原型的处理

前序 P4 原型包已清理，不再作为当前推荐评审入口。

当前推荐用户评审 v8。
