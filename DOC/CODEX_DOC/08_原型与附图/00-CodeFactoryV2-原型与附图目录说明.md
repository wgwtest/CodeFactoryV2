# CodeFactoryV2 原型与附图目录说明

本目录是 CodeFactoryV2 当前正式原型与附图根目录。

## 目录规则

1. 当前仍可作为设计评审、前端实现和界面验收依据的原型包放在本目录。
2. 每一轮原型使用独立版本包，命名格式为 `YYYY-MM-DD-HHMMSS-CodeFactoryV2-<主题>-vN/`。
3. 已评审版本不得原地覆盖；新方向、新关键布局或新事实源变化必须创建下一版目录。
4. 每个版本包必须包含 `README.md`、`source/`、渲染后的评审图片；如引用外部材料或历史原型截图，放入 `original/` 并说明来源。
5. 桌面整页原型默认使用 `1920 x 1080` 画板，不得用浏览器临时窗口比例替代。
