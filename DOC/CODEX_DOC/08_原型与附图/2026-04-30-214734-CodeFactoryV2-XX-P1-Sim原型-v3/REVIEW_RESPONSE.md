# v1 / v2 评审响应

## 用户批注

用户指出：

1. 本轮需求类似已有 `XX-P2-Sim`、`XX-P3-Sim`、`XX-P5-Sim`，命名不应新造。
2. P2 缺的是 P1 上游子系统输入，不缺专家输入模拟。
3. 模拟器应模拟 P1 注册、领域目录和知识输出。
4. P2 主界面由用户选择领域知识并加载。
5. 不应出现“场景”“样例数据发生器”“成型软件目录”等概念。

## 判断

批注成立。v1 错在把发生器嵌入 P2 编辑器设置弹层；v2 错在做成独立 P2 样例数据发生器，仍然承担了 P2 不需要的样例/会话生成语义。

## v3 处理

1. 统一命名为 `XX-P1-Sim`。
2. v3 只模拟 P1 发布态知识服务。
3. `XX-P1-Sim` 提供服务注册、领域目录、知识包输出、重置和调用日志。
4. P2 专家工作台选择领域知识并加载。
5. P2 编辑器保持普通需求规格编辑体验，不显示 sim、mock 或发生器概念。
