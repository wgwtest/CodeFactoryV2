# CodeFactoryV2 P3 上下文 Inspector 双 Tab 原型 v15

## 原型目的

本原型用于验证 P3 软设工作区右侧上下文 `Inspector` 的双 Tab 目标态视觉方案，重点表达：

- 选中阶段节点时，第一屏展示来源、冻结状态、下游承接和可执行动作。
- 选中阶段关系箭头时，第一屏展示转换策略、执行按钮、进度反馈和输出反馈。
- 选中文档块时，第一屏展示条款摘要、软设承接、质量反馈和局部动作。
- Inspector 内部固定为“能力 / 共性信息”两个页签。
- “能力”页默认打开，承载当前对象的可执行工作。
- “共性信息”页用于显式表达基类抽象，包括标识、布局、追溯、生命周期；关系对象额外展示关系扩展。

## 查看方式

直接用浏览器打开 `source/p3-inspector-property-groups-prototype.html`。页面内通过点击画布对象切换三种选中状态，并在 Inspector 内部切换“能力 / 共性信息”：

- 阶段节点
- 阶段关系
- 文档块

## 评审关注点

1. 右侧 Inspector 是否像真实产品工作面板，而不是属性 Schema 展示页。
2. 阶段关系箭头是否能作为“可执行关系对象”承载转换控制、进度和反馈。
3. “能力”页是否能把当前对象的关键动作放在第一屏。
4. “共性信息”页是否能清楚体现 Inspector 基类字段，而不影响能力页的工作效率。
5. 阶段节点、阶段关系、文档块三类对象切换时，是否既共享基类结构，又保留各自专属能力。
