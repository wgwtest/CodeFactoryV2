被演进对象轨迹卡

1. 从哪里来

该资产最初来自 P3 的航路规划需求工单，经 P4 审定进入制造，并登记为 ToolDefinition。

2. 为什么被演进

自演进巡检发现真实验证样例缺失，影响 P5 对该工具的可取用信心。

3. 变更了什么

新增验证样例、补齐 ToolFetchManifest 依赖 hash，并刷新 P5 查询投影。

4. 如何回退

低风险改写保留 EvolutionRollbackRecord；回退后恢复上一版 manifest 和验证状态。
