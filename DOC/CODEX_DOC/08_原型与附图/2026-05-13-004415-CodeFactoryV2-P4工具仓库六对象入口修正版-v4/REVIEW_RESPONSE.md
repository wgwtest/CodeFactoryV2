# P4 v3 用户批注处理说明

## 1. 批注结论

用户对 `P4 左侧对象导航修正版 v3` 的批注成立。

v3 只修正了“顶部 Tab 改左侧对象导航”的大方向，但信息架构仍然过粗：

- 左侧存在 6 个对象入口。
- README 第六章只拆成 3 个小节。
- 三张评审图无法解释 6 个入口之间的对应关系。
- 列表态、详情态、资产视角、演进行为和被演进对象轨迹混在一起。

## 2. 本版修正方式

v4 不覆盖 v3，另建正式原型版本包。

v4 将左侧 6 个入口与 6 张评审图一一对应：

| 左侧入口 | v4 图 | 修正重点 |
| --- | --- | --- |
| 需求工单列表 | `01-1920x1080-P4需求工单列表.png` | 先看有多少 P3 工具需求工单，以及每单拆出多少叶子工具需求 |
| 单工具需求配置 | `02-1920x1080-P4单工具需求配置.png` | 点中某个叶子工具需求后，再配置匹配、审定、制造和交付 |
| 工具资产资源列表 | `03-1920x1080-P4工具资产资源列表.png` | 从资产本身出发查看仓库资源、分类、验证状态和覆盖缺口 |
| 单工具资产属性 | `04-1920x1080-P4单工具资产属性.png` | 点中某个资产后查看身份、输入输出合同、fetch、版本和引用关系 |
| 演进行为动作 | `05-1920x1080-P4演进行为动作.png` | 单独表达巡检、发现、采纳、忽略、生成任务和回退这些行为 |
| 被演进对象脉络轨迹 | `06-1920x1080-P4被演进对象脉络轨迹.png` | 从被演进工具本身追踪需求、资产、发现、变更集和回退记录 |

## 3. 对 v3 的处理

v3 保留为过程版本，不再作为当前推荐评审入口。

当前推荐用户评审 v4。
