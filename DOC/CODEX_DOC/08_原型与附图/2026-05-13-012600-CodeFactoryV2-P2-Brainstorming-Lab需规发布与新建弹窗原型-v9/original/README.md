# 原始材料说明

v9 继承 v6 的真实运行系统截图作为运行层事实源，继承 v8 的“4.1 单栏需规列表”设计方向，并新增用户对 v8 行内动作和新建弹窗的批注作为本版调整依据。

## 1. 继承材料

`runtime-screens/` 中的截图来自 v6，说明当前真实 Lab 已具备复杂组织器配置、会话过程产物、Turn 审计和 Provider 调用日志。

这些截图继续作为 v9 中 `组织器配置`、`会话管理`、`当前 Turn`、`调用日志` 的事实源。

## 2. 继承设计方向

v8 已确立：4.1 只做需求规格说明对象列表，右侧当前需规详情移除，4.2 才展开组织器配置。

## 3. 新增事实源

用户在 2026-05-13 进一步提出：

```text
打开、编辑、进入配置不是同样的功能吗？应该是两个按钮，一个是进入配置，一个是发布。发布之后就可以被 P3 收到。新建需规按钮需要弹出一个模态窗口。
```

v9 的新增变化由该批注意图驱动：行内动作收敛为 `进入配置 / 发布`，并新增新建需规模态窗口状态图。
