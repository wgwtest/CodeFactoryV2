## 继承约束

1. v15 的五张同屏卡片只能压缩 v12 / v14 的结构，不得删除顶部方形用户积木、左右端口、总体状态、实时计数和底部队列。
2. v15 不把 `行业用户` 画成独立卡片；行业用户已内化为需求分析系统顶部接入用户积木。
3. v15 不把 P6 画成 P1-P5 的输出接口；P5 的终端输出是 `交付目录`。
4. v15 不复写历史原型包；本目录只保存用于本轮评审的来源截图副本。
