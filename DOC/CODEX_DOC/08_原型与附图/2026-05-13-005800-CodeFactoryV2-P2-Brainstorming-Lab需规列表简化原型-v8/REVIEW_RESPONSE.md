# v8 评审响应

## 1. 评审背景

v7 在真实 Lab 骨架前新增了 `需求规格说明管理` 首 Tab，但 4.1 同时放入了右侧“当前需规”详情面板，导致管理页显得像已经与 4.2 组织器配置合并。

用户本轮明确反馈：

```text
4.1 用第一页就行，用不着那么多内容。右侧当前需规这些配置没那么大必要。除非计划把 4.1 和 4.2 合并，但现在不想非得合并。4.1 简单一点，就是需规的列表就行。右侧当前需规可以先移除。
```

## 2. 已吸收的批注

### 批注 1：4.1 简化为列表页

处理结果：

- 4.1 改为单栏 `需求规格说明管理` 列表。
- 保留搜索、状态筛选、模板筛选和 `新建需规` 主动作。
- 列表行保留 `打开`、`编辑`、`进入配置` 操作。

### 批注 2：移除右侧当前需规详情

处理结果：

- 删除 v7 中 4.1 右侧当前需规详情面板。
- 删除 4.1 内的模板绑定、组织器配置档、Provider、知识绑定、会话摘要和正文摘要展示。
- 这些内容继续留在 4.2 及后续运行层页面表达。

### 批注 3：暂不合并 4.1 和 4.2

处理结果：

- v8 明确把 4.1 定义为业务对象列表入口。
- 4.2 继续作为选中需规后的组织器配置工作台。
- README 将“是否合并 4.1 / 4.2”列为后续问题，不在本版决策。

## 3. 本版结论

v8 的核心结论是：

```text
4.1 只做需求规格说明对象列表；4.2 才展开当前需规对象下的组织器配置。
```

本版当前仍需用户确认。
