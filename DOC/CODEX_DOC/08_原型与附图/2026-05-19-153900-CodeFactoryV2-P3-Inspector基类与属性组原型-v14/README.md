# CodeFactoryV2 P3 上下文 Inspector 原型 v14

## 原型目的

本原型用于验证 P3 软设工作区右侧上下文 `Inspector` 的目标态视觉方案，重点表达：

- 选中阶段节点时，第一屏展示来源、冻结状态、下游承接和可执行动作。
- 选中阶段关系箭头时，第一屏展示转换策略、执行按钮、进度反馈和输出反馈。
- 选中文档块时，第一屏展示条款摘要、软设承接、质量反馈和局部动作。
- 对象元信息和几何属性保留在低权重折叠区，不抢占主工作流内容。

- 阶段节点
- 阶段关系
- 文档块

## 评审关注点

1. 右侧 Inspector 是否像真实产品工作面板，而不是属性 Schema 展示页。
2. 阶段关系箭头是否能作为“可执行关系对象”承载转换控制、进度和反馈。
3. 阶段节点、阶段关系、文档块三类对象是否都能把关键动作放在第一屏。
4. 低权重对象属性是否保留了可追溯信息，同时不干扰主要工作流。
5. 三种对象切换时，选中焦点是否明确，不出现误导性的双焦点。
