## 3. 当前设计口径

`XX-P1-Sim` 是 P1 上游知识服务模拟器。

它提供：

- P1 模拟服务注册。
- 领域知识目录。
- 发布态领域知识包。
- 固定种子 / 固定版本 / 重置。
- 调用日志。

它不提供：

- 专家问答模拟。
- P2 需求规格正文生成。
- P2 文档或会话创建。
- 问答补齐、自动补齐。
- 缺口检查、冻结。
- P3 可消费包。
- 成型软件目录。

P2 专家工作台负责：

- 发现 `XX-P1-Sim`。
- 选择领域知识，例如 `空域规划领域知识`。
- 加载概念、规则、流程、约束和证据。
- 进入普通需求规格编辑器。
- 由用户确定目标软件名称，例如 `空域运算软件`。
