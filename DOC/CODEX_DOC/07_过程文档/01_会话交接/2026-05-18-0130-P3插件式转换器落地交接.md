## 3. 关键边界

当前分支负责：

- 转换器协议。
- 插件发现与注册。
- adapter 加载。
- Dify Workflow API 调用边界。
- `result_json` 解析和本地输出校验。
- P3 会话状态落库与现有页面 DTO 兼容。
- mocked HTTP 测试。

当前分支不负责：

- 登录或编辑 Dify 工作台。
- 保存真实 Dify API Key。
- 维护 Dify 内部节点状态。
- 把 Dify 内部调试过程作为 P3 分系统事实源。
