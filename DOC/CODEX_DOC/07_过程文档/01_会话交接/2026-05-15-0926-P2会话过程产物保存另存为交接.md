# 2026-05-15 P2 会话过程产物保存/另存为交接

## 1. 本轮目标

在 P2 需求分析组织器 Lab 的“会话管理”页签中，补充当前会话过程产物的 `保存` 和 `另存为` 能力。

## 2. 已完成内容

- 在“会话摘要 / 过程产物”标题行右侧增加 `保存`、`另存为` 按钮。
- `保存` 调用 `POST /api/requirement-analysis/spec-items/{id}/save-session-artifacts`。
- `另存为` 打开模态窗口，填写新需规标题后调用 `POST /api/requirement-analysis/spec-items/{id}/save-session-artifacts-as`。
- 后端将当前会话的以下内容写入 authoring 文档 `semantic_state.lab_session_artifacts`：
  - `decision_state_document`
  - `working_document`
  - `spec_tree`
  - `turn_path`
  - `session_id`
  - `topic`
- `另存为` 会创建新的 `RequirementSpecWorkItem`，并保留原会话过程产物引用。
