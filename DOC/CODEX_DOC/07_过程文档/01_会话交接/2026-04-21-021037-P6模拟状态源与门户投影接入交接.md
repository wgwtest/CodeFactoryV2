# P6 模拟状态源与门户投影接入交接

## 1. 本轮目标

把 `P6.2.5 模拟状态源` 从正式设计落实到代码，并让 `/portal` 改为消费 `P6` 公共投影接口。

## 2. 本轮已完成内容

- 新增后端 `P6` 公共读侧模块：
  - `apps/api/app/p6/models.py`
  - `apps/api/app/p6/mock_scenarios.py`
  - `apps/api/app/p6/service.py`
  - `apps/api/app/api/routes/p6.py`
- 在 `apps/api/app/main.py` 注册 `p6` 路由
- 新增后端测试：
  - `apps/api/tests/test_p6_api.py`
- 新增前端客户端：
  - `apps/web/src/lib/p6.ts`
- 将 `/portal` 改造成 API 驱动门户：
  - 页面进入后读取 `mock-scenarios`
  - 读取 `portal-projection`
  - 页面右上角显示 `模拟源` 与三套场景切换
  - 蓝图节点改为消费阶段状态卡 / 参与用户负载
  - 保留布局切换、拖拽记忆、关系视图切换、双击跳转
- 更新前端测试：
  - `apps/web/src/test/P6PortalPage.test.tsx`
  - `apps/web/src/test/p6PortalGeometry.test.ts`

## 3. 关键实现结论

- `P6` 首版仍然只读 `mock` 源，不连接 `P1 ~ P5` 真实接口。
- `live` 调用明确返回 `501`，避免伪装成功。
- `/portal` 不再依赖 `p6PortalData.ts` 中的静态业务节点数据，改为：
  - 后端投影提供语义数据
  - 前端本地只保留布局 preset 与展示映射
- 五阶段系统节点与参与用户节点都已经按正式设计中的字段结构渲染。
