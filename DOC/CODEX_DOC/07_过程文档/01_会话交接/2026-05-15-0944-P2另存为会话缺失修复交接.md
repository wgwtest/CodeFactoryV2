# 2026-05-15 P2 另存为会话缺失修复交接

## 1. 本轮目标

修复 P2 需求分析组织器 Lab 中 `另存为` 提示 `Requirement Analysis session not found` 的问题。

## 2. 根因结论

`启动验证` 创建的是页面当前会话，但不会在当前需规对象上持久化 `analysis_session_id`。后端保存/另存为接口此前只读取需规对象上的 `analysis_session_id`，因此在未绑定会话的需规对象上另存会失败。

## 3. 已完成修复

- 前端 `保存` 请求体增加 `session_id`。
- 前端 `另存为` 请求体增加 `session_id`。
- 后端 `save-session-artifacts` 支持可选 `session_id`。
- 后端 `save-session-artifacts-as` 支持可选 `session_id`。
- 后端成功保存后回写当前 `RequirementSpecWorkItem.analysis_session_id`。
- 补充前后端回归测试。
