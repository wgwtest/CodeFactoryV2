# 2026-05-10 P2 组织器多轮整改第 4 轮问题与整改说明

## 1. 背景

本文件配套第 4 轮受控动态多轮测试记录：

```text
DOC/CODEX_DOC/06_测试文档/03_机测记录/2026-05-10-P2-组织器多轮整改第4轮测试记录.md
```

本轮继续遵守“当轮发现问题，当轮尽量全量整改并复测”的策略。

## 2. 问题与根因

### 2.1 决策项不沉淀

现象：

- 第 4 轮基线中两个组织器 `confirmed_decisions=0`。
- 用户已经回答多个关键口径，但结构化状态仍以事实为主，无法支撑下一步规划。

根因：

- `decision_state_delta` Prompt 没有把“回答组织器问题时明确给出的定位、范围、角色、流程、数据、非功能、验收”定义为决策链内容。
- Dify 旧远端输出可能只返回 `confirmed_facts`，不返回 `confirmed_decisions`。

整改：

- 更新 `brainstorm-v1` Prompt，明确决策型事实必须进入 `confirmed_decisions`。
- 更新 Dify `document_projection` 节点，生成决策型记录。
- 更新 Dify adapter，对旧远端输出做兼容提升，将决策型事实补入 `confirmed_decisions`。

### 2.2 Dify 草案口语噪声残留

现象：

- Dify 最终正文中残留“这个我还没完全想清楚”等考官口语。

根因：

- 本地节点已清洗事实文本，但远端 Dify workflow 未发布或旧输出仍可能返回原始口语化 patch。
- Adapter 只归一化状态，没有清洗远端 `document_patch.content` 与 `filled_document_text`。

整改：

- Dify 节点继续清洗不确定性前缀。
- Dify adapter 在远端结果归一化阶段清洗常见口语噪声。

### 2.3 Dify 过早建议回看或草案

现象：

- Dify 在异常、验收等核心缺口未完全闭合时，出现“当前关键信息已较完整，是否回看闭合项或直接输出草案？”。

根因：

- `_next_gap_plan` 的回看/草案阈值只看记录数量和核心章节数量，没有要求异常与验收章节闭合。

整改：

- 收紧 Dify `document_projection._next_gap_plan` 阈值：只有异常与验收均已有信息时，才允许进入回看或草案入口。
- 修正非功能分类顺序，让“地图浏览流畅、可接受时间”优先归入性能，而不是被“数据来源、参数、适用限制”抢到精度质量。

### 2.4 `brainstorm-v1` 反复追问第一阶段纳入范围

现象：

- `brainstorm-v1` 中段多轮追问“四个角色和九项功能是否全部纳入第一阶段”。
- 动态考官被迫触发 `small_guidance`。

根因：

- Prompt 对“软件名称/背景领域”已降级，但没有把“第一阶段纳入范围”这类问题也纳入重复追问控制。
- 动态考官问题匹配中，“范围/第一阶段”可能被软件定位或数据接口抢先匹配，未优先释放 `scope_boundary`。

整改：

- `next_interaction_planning.system.md` 增加规则：第一阶段角色覆盖范围、核心功能是否全部纳入第一阶段不得连续两轮以上反复追问，应转为待确认事项并推进数据、异常、非功能或验收。
- `scripts/p2_orchestrator_multiturn_probe.py` 增加动态考官优先规则：问题出现“不做哪些范围”“能力只做辅助分析”“全部纳入第一阶段”等表达时，优先释放 `scope_boundary`。

### 2.5 外部模型余额不足导致真实长测阻塞

现象：

- 第三次复测中 `brainstorm-v1` 第 1 Turn 返回 500。
- 后端日志显示 DeepSeek 返回 `402 Insufficient Balance`。
- Dify workflow 手工调用显示内部模型同样返回 `402 Insufficient Balance`。

根因：

- 外部模型服务额度不足。
- Dify adapter 原先把 workflow failed 丢失成“没有 result_json”，不利于诊断。

整改：

- API 层已有 `ValueError -> 400` 映射，本轮补测试确保 provider 失败能返回可读 400。
- Dify adapter 增加 workflow `status=failed` 或 `data.error` 识别，错误信息包含 workflow run id 和原始 error。
