- 存在清晰的主文种归并规则
- 归并规则已同步到总说明、来源映射、缺口清单和路线图

## 3. 验收项

1. 检查 `03-阶段专题投影归并矩阵.md` 是否明确回答“投影稿不是最终终态”。
2. 检查归并矩阵是否为每份 `10 ~ 21` 投影稿给出主归并去向、辅归并去向和保留方式。
3. 检查 `README.md` 是否把归并矩阵纳入阅读顺序，并明确“先拆投影，再按文种归并”。
4. 检查标准文档包总说明是否把阶段专题投影层标为“过渡追溯层”。
5. 检查缺口清单是否新增“文种收敛缺口”。
6. 检查路线图是否已把“完成主文种归并”提升为第一优先级。

## 4. 验收方法

1. 阅读 `DOC/JB_DOC/04-映射与追溯/03-阶段专题投影归并矩阵.md`。
2. 对照阅读 `README.md` 与 `00-平台自身标准文档包总说明.md`。
3. 对照阅读 `00-CODEX_DOC到JB_DOC来源映射总表.md`、`01-标准覆盖缺口清单.md`、`02-文种优先级路线图.md`。
