# 2026-05-15 P2 另存为会话缺失修复自测记录

## 1. 问题现象

用户在“会话管理”页签点击 `另存为` 时，页面提示：

```text
Requirement Analysis session not found
```

## 2. 根因

页面可以通过“组织器配置”的 `启动验证` 直接创建 `RequirementAnalysisSession`，但该路径不会自动把新建的 `session_id` 回写到当前 `RequirementSpecWorkItem.analysis_session_id`。

原后端保存/另存为接口只从需规对象的 `analysis_session_id` 查找会话。当当前页面已经有会话、但需规对象尚未绑定会话时，后端会误判为会话不存在。

## 3. 修复内容

- `保存` 和 `另存为` 请求体显式携带当前页面 `session_id`。
- 后端保存/另存为接口优先使用请求体中的 `session_id`。
- 后端在保存/另存为成功后，将该 `session_id` 回写到当前需规对象。
- 增加后端回归测试，覆盖“需规对象未绑定会话，但请求体显式提供 session_id”的路径。
- 更新前端测试，确保保存/另存为请求会携带当前页面会话 ID。
