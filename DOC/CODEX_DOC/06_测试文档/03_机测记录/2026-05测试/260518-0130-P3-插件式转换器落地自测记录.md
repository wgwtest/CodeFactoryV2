## 2.1 白屏修复补充

真实 Dify workflow 返回的 `workorder_projection_candidate` 首版形态为：

```text
candidate_batches
```

而旧前端工作台 DTO 期望：

```text
tree
items
```

同时真实 Dify 模块字段使用 `id/title`，旧前端工作台 DTO 期望 `module_id/name`。本轮已在 `software_design_v2` 服务层增加归一化：

- `id/title` -> `module_id/name`
- `candidate_batches` -> `tree/items`

归一化后前端不再因为缺少 `items.map` 所需数组而白屏。
