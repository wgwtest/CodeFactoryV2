## 1. 测试目的

第 4 轮用于验证第 3 轮识别出的决策链与下一问质量问题。重点包括：

1. `confirmed_decisions` 是否能沉淀角色、边界、流程、数据、非功能和验收口径。
2. `brainstorm-v1` 是否减少反复追问软件名称、背景领域、第一阶段角色和功能纳入范围。
3. `brainstorm-v1-dify-workflow` 是否避免在异常、验收等核心缺口未闭合前过早建议回看或草案。
4. 草案正文是否清理用户口语噪声和未确认领域示例。
5. 外部模型失败时是否能暴露可诊断错误。


该次复测用于验证动态考官优先释放范围边界事实、`brainstorm-v1` 不再连续追问第一阶段纳入范围。测试未能进入有效 Turn，原因不是组织器业务逻辑，而是外部模型服务失败：

| 组织器 | Turn | HTTP | 直接错误 |
| --- | ---: | ---: | --- |
| `brainstorm-v1` | 1 | 500 | DeepSeek 返回 `402 Insufficient Balance` |
| `brainstorm-v1-dify-workflow` | 1 | 400 | Dify workflow 内部模型返回 `402 Insufficient Balance`，无 `result_json` |

手工调用 Dify workflow 复核结果：

```text
workflow status: failed
error: API request failed with status code 402: Insufficient Balance
workflow_run_id: ee50f2a5-babc-4a56-8074-60cb18b7c02e
```

因此，本次复测不能作为组织器质量退化证据，只能作为外部 Provider 不可用证据。恢复 DeepSeek/Dify 内部模型额度后，应从第三次复测入口继续执行。
