# P6 门户模拟流速降频自检记录

时间：2026-04-30 13:30:41

## 1. 目标

用户确认数据驱动连线方向正确，但指出模拟数据频率过快。本轮目标是降低 mock 合同中的流速，避免画布上 payload 过密，同时保留“速率多少就生成多少运动对象”的一对一语义。

## 2. 调整口径

本轮不改连线关系、不改五卡布局、不改 payload 数据驱动机制，只降低 mock 展示合同中的运行频率：

| 流 | 原频率 | 新频率 |
| --- | --- | --- |
| `P1 -> P2` 知识 | `12 条/小时` | `5 条/小时` |
| `P2 -> P3` 规格 | `8 份/小时` | `4 份/小时` |
| `P3 -> P4` 工单 | `11 包/小时` | `5 包/小时` |
| `P3 -> P5` 基线 | `6 份/小时` | `3 份/小时` |
| `P4 -> P5` 工具 | `10 项/小时` | `4 项/小时` |
| `P5 -> 交付目录` 目录 | `4 个/日` | `2 个/日` |

辅助实时指标同步降低：

- `P1` 正在入库：`18 条/小时` -> `8 条/小时`
- `P4` 正在匹配：`14 项/小时` -> `7 项/小时`
- `P5` 正在装配：`7 项` -> `4 项`
