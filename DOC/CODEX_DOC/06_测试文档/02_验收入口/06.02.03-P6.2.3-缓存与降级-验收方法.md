## 3. 操作步骤

1. 打开 `/observation`。
2. 检查页面是否展示 warning / blocked 或等价的阶段告警信息。
3. 检查页面是否能看到数据新鲜度、降级原因或等价提示。
4. 打开 `delivery-gap` 观察投影响应，确认页面上的告警和降级提示能在正式投影字段中找到来源。
5. 如果页面出现异常数据，确认页面仍可观察，而不是整页失效。

## 4. 通过标准

- 观察页能显示告警与降级信息。
- 新鲜度与降级原因对外可见。
- 异常时平台保持可观察。

## 5. 失败时记录

- 哪类告警或降级提示缺失。
- 页面是否出现整体失效。
