## 1. 页面入口

- [ ] `http://127.0.0.1:5182/portal` 可打开并显示门户蓝图。
- [ ] `http://127.0.0.1:5182/observation` 可打开并显示串行观察页。

## 2. 正式接口

- [ ] `GET /api/p6/mock-scenarios` 可返回 `baseline / review-pressure / delivery-gap` 三个场景。
- [ ] `GET /api/p6/portal-projection` 可返回门户投影。
- [ ] `GET /api/p6/observation-projection` 可返回观察投影。
- [ ] `GET /api/platform-config/display-baseline` 可返回 `p6.3-v1` 展示基线。
- [ ] `GET /api/platform-config/routes` 可返回 `/portal`、`/observation` 与阶段路由。
- [ ] `GET /api/platform-config/legend` 可返回图例与路线图配置。
- [ ] `GET /api/platform-display/workbench`、`GET/POST /api/platform-display/experiments`、`GET /api/platform-display/promotion-candidates` 可正常工作。

## 3. P6.1 与 P6.2 页面行为
