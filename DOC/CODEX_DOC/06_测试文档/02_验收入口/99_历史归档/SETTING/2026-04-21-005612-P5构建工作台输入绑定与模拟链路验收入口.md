## 3. 验收项

1. `P5` 工作台可以读取设计输入和供给输入列表。
2. 主单可以确认输入绑定，且确认后状态可回显。
3. 缺口模块可以在工作台中执行模块级工具绑定。
4. 反馈任务可以在工作台中执行确认 / 忽略。
5. `XX-P3-DOC-SIM` 可以生成设计模拟输入并创建 `P5` 主单。
6. `XX-P4-SUPPLY-SIM` 可以生成供给模拟输入并回到 `P5` 工作台。
7. 后端 `software_build` API 测试与前端 `P5` 相关页面测试通过。
