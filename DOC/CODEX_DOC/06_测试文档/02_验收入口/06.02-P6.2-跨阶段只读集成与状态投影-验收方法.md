  - `http://127.0.0.1:8050/api/p6/observation-projection?source=mock&scenario=delivery-gap`

## 3. 操作步骤

1. 依次访问四个正式读接口，确认均可返回。
2. 查看 `stage-snapshots`，确认每个阶段都形成统一快照和节点状态负载。
3. 查看 `observation-projection`，确认其中包含新鲜度、告警或降级相关信息。
4. 打开 `/portal` 与 `/observation`，确认页面消费的是上述正式接口，而不是页面私有常量。
5. 确认当前读源为 `mock`，`live` 未接通时应显式暴露未实现状态，而不是伪装成正常空数据。

## 4. 通过标准

- 四个读接口正常。
- 统一快照、统一投影和降级信息存在。
- 两个页面都消费正式接口。
- `mock / live` 边界清楚。

## 5. 失败时记录

- 失败接口或失败页面。
- 错误属于查询、模型、降级还是页面消费层。
- 是否需要继续下钻 `P6.2.1 ~ P6.2.5`。
