## 2. 测试入口

- `http://127.0.0.1:8050/api/p6/mock-scenarios`
- `http://127.0.0.1:8050/api/p6/stage-snapshots?source=mock&scenario=baseline`
- `http://127.0.0.1:8050/api/p6/portal-projection?source=mock&scenario=baseline`
- `http://127.0.0.1:8050/api/p6/observation-projection?source=mock&scenario=delivery-gap`

## 3. 操作步骤

1. 依次访问四个正式读接口，确认都返回 JSON。
2. 把 `source=live` 代入读接口，确认返回明确未实现状态。
3. 把非法 `scenario` 代入读接口，确认返回 `404` 或等价缺失场景错误。
4. 记录哪一个接口异常，或异常是否只发生在特定参数组合下。

## 4. 通过标准

- 四个正式读接口可用。
- 非法 `scenario` 被拒绝。
- `source=live` 不伪装成正常数据。

## 5. 失败时记录

- 失败接口和失败参数。
- 返回内容是 `404`、参数错误还是未实现状态。
