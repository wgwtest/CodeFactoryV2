## 3. 操作步骤

1. 打开 `stage-snapshots` 响应。
2. 逐个检查 `P1 ~ P5` 阶段是否都形成统一快照对象。
3. 检查每个阶段是否都包含 headline、摘要、指标、入口状态、健康状态和时间戳。
4. 对照 `/portal` 或 `/observation` 页面中显示的阶段信息，确认字段含义一致。

## 4. 通过标准

- 每个阶段都形成统一快照。
- 状态负载字段齐全。
- 页面显示与快照字段一致。

## 5. 失败时记录

- 哪个阶段缺字段。
- 哪个字段和页面显示不一致。
