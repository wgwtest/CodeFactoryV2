## 3. 操作步骤

1. 打开 `/portal`，确认门户节点和关系已显示。
2. 切换推荐布局 / 个人布局，确认两种布局模式都能使用。
3. 拖动任一系统节点，确认它不会被拖出门户世界边界。
4. 对页面执行缩放和平移，确认节点和关系不会整体失真。
5. 若页面支持重置布局，执行一次恢复，确认可回到推荐布局。

## 4. 通过标准

- 布局切换可用。
- 节点拖拽受边界约束。
- 缩放和平移不会破坏节点与关系的整体显示。
- 个人布局只影响位置 / 相机状态，不改写节点语义。

## 5. 失败时记录

- 哪种交互动作失败。
- 是否能稳定复现。
- 是否需要继续定位到画布、几何或投影适配层。
