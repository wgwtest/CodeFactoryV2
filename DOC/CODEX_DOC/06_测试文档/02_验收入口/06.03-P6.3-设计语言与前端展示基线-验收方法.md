## 2. 测试入口

- 页面：
  - `http://127.0.0.1:5182/portal`
  - `http://127.0.0.1:5182/observation`
- 接口：
  - `http://127.0.0.1:8050/api/platform-config/display-baseline`
  - `http://127.0.0.1:8050/api/platform-config/routes`
  - `http://127.0.0.1:8050/api/platform-config/legend`

## 3. 操作步骤

1. 访问 `display-baseline`，确认返回 `p6.3-v1` 或等价正式展示基线标识。
2. 访问 `routes` 与 `legend`，确认都返回正式配置。
3. 打开 `/portal` 与 `/observation`，确认两者都显式继承平台展示基线，而不是完全硬编码。
4. 检查系统节点、参与用户节点、产物节点和状态注记节点的视觉区分是否成立。

## 4. 通过标准

- 三个配置接口正常。
- 门户页与观察页共同继承同一套基线。
- 四类节点视觉基线已形成。

## 5. 失败时记录

- 哪个配置接口缺失。
- 哪个页面仍依赖局部硬编码。
- 哪类节点视觉区分不成立。
