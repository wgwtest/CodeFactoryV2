# 验收主入口

- 文档角色：当前人工验收统一主入口
- 当前目录规则：先看本页，再进入对应节点的 `验收方法`；已发生轮次统一归档到 `99_历史归档/`

## 1. 使用方式

1. 如果你要开始当前轮人工验收，先看本页。
2. 再按节点编码直接打开对应 `验收方法` 文件。
3. `验收方法` 里写的是具体怎么测，不是导览。
4. 人测完成后，把结果回写到对应 `人测记录` 与 `验收结论`。
