## 2. 测试入口

- 页面：
  - `http://127.0.0.1:5182/portal`
  - `http://127.0.0.1:5182/observation`
- 接口：
  - `http://127.0.0.1:8050/api/p6/portal-projection?source=mock&scenario=baseline`
  - `http://127.0.0.1:8050/api/p6/observation-projection?source=mock&scenario=baseline`

## 3. 操作步骤

1. 打开 `/portal`，记录当前门户摘要和节点显示。
2. 打开 `/observation`，记录当前观察摘要和阶段状态。
3. 打开对应接口响应，确认页面展示可以在接口包络中找到来源字段。
4. 切换场景，确认页面跟随正式接口响应变化，而不是保持本地伪造常量不变。

## 4. 通过标准

- 两个页面都消费正式接口包络。
- 场景切换会同步刷新页面。
- 页面不依赖前端私有常量伪造数据。

## 5. 失败时记录

- 哪个页面与接口不一致。
- 场景切换后哪些对象没有刷新。
