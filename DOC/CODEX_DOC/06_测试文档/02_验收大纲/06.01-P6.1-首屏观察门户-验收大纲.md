# `P6.1` 首屏观察门户验收大纲

- 节点编码：`06.01`
- 节点名称：`P6.1` 首屏观察门户

## 1. 验收目标

验证 `/portal` 是否已经形成独立门户蓝图页，并能稳定承载节点、连线、图例、布局与跳转能力。

## 2. 验收范围

- 门户独立路由
- 蓝图画布
- 节点、连线、产物
- 图例与摘要
- 布局切换
- 场景切换
- 实验台入口

## 3. 前置条件

- `PortalProjection` 可通过正式接口返回
- 平台路由、图例和展示基线可通过正式接口返回
- 浏览器可访问 `/portal`

## 4. 必须通过项

- `/portal` 不回退到主壳层菜单页
- 系统节点、参与用户节点、产物节点三类对象可见
- 单击节点仅高亮，不弹出遮挡主画布的详情弹窗
- 双击系统节点可进入稳定模块路由
- 推荐布局 / 个人布局切换可用
- 门户图例、知识上下文和平台提示可见

## 5. 条件通过项

- 节点拖拽与个人布局记忆可作为增强项验证
- 语义线 / 投影聚合切换的具体视觉风格允许继续优化
- 实验台首版只要求通过小按钮进入，不要求单独页面承载

## 6. 非本轮验收范围

- 多人协同编辑门户布局
- 门户内直接修改业务数据
- 登录与权限流程

## 7. 验收入口

- 页面：
  - `/portal`
- 接口：
  - `/api/p6/mock-scenarios`
  - `/api/p6/portal-projection`
  - `/api/platform-config/display-baseline`
  - `/api/platform-config/routes`
  - `/api/platform-config/legend`
  - `/api/platform-display/workbench`

## 8. 判定规则

- 所有必须通过项通过，则节点可判通过
- 条件通过项未完全满足但门户主闭环稳定时，可记为待优化
