# `P6.1.2` 连线语义与流向表达验收大纲

- 节点编码：`06.01.02`
- 节点名称：`P6.1.2` 连线语义与流向表达

## 1. 验收目标

验证门户蓝图中的连线是否已经形成稳定的语义表达，并能在不同视图与交互状态下保持正确的流向和锚点对齐。

## 2. 验收范围

- 语义连线
- 锚点 / pin
- 语义线 / 投影聚合双视图
- 产物与连线的联动关系

## 3. 前置条件

- `PortalProjection.flow_list` 已由正式接口返回
- 门户节点可稳定渲染
- 浏览器可访问 `/portal`

## 4. 必须通过项

- 每条正式连线都声明 `semantic_type`
- 连线从锚点 / pin 出发，而不是从节点中心出发
- 缩放、拖拽和布局切换后，连线仍与锚点保持对齐
- 语义线 / 投影聚合切换只改变展示方式，不改变关系语义

## 5. 条件通过项

- 连线标签和拥塞缓解视觉可继续优化
- 投影聚合视图中的产物摘要允许继续调整信息密度

## 6. 非本轮验收范围

- 节点卡片内容结构
- 多人协同布局编辑
- 关系的自动避障算法升级

## 7. 验收入口

- 页面：
  - `/portal`
- 接口：
  - `/api/p6/portal-projection`
- 代码：
  - `apps/web/src/components/p6/P6BlueprintCanvas.tsx`
  - `apps/web/src/components/p6/p6PortalProjection.ts`

## 8. 判定规则

- 所有必须通过项通过，则节点可判通过
- 若连线与锚点长期错位，或视图切换改写了关系语义，则节点不得判通过
