# WBS-P6 门户与平台入口研制计划

## 1. 节点目标

建设平台首页、导航、权限与模块入口层，为 `P1 ~ P5` 提供统一入口和态势化承载面。

## 2. 当前边界

`P6` 负责：

- 门户首页
- 模块入口编排
- 可视化态势表达
- 平台级入口逻辑

不负责：

- 替代任一业务子系统
- 承担 `P1 ~ P5` 内部业务逻辑

## 6. 后续约束

- `P6` 必须保持对业务主链的解耦
- 门户只承载入口和观察，不定义业务主链的正式数据契约
