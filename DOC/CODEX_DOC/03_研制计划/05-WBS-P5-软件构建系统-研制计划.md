# WBS-P5 软件构建系统研制计划

## 1. 节点目标

基于需求规格、软件设计对象以及工具资产匹配结果，形成可运行的软件或元数据应用。

## 2. 当前边界

`P5` 负责：

- 软件装配
- 运行时生成
- 结果交付
- 新资产反哺

不负责：

- 业务知识抽取
- 需求建模
- 软件设计对象生成
- 工具资产治理

- `DOC/CODEX_DOC/02_设计说明/00-软件工厂平台总体设计.md`

当前前置设计与过程稿入口：

- `docs/superpowers/specs/2026-04-19-xx-p5-software-construction-system-design.md`

## 4. 当前状态

- 仍处于总纲定义阶段
- 已启动独立 `superpowers` 方案线
- 当前已完成前置边界收敛，但尚未转写为正式详细设计

## 5. 后续约束

- `P5` 启动前必须明确消费对象：
  - `RequirementSpec`
  - `SoftwareDesignModel`
  - 工具/组件匹配结果
- 不应绕过 `P3 / P4` 直接从页面草稿装配系统
- `P3` 必须先冻结唯一实现路线，`P5` 不负责自行决定技术路线
- `P5` 以 `P3` 冻结设计为主输入，以 `P4` 已审定 / 已供给资产为辅输入
- `P5` 发现问题后只输出问题报告与反馈任务，`P3` 是唯一回流仲裁者
- `P4` 不直接接受 `P5` 修订回流，只接受 `P3` 发起的新供给任务 / 派生任务 / 组件拆分任务
- `P5` 首版交付物以本地独立交付目录为第一载体，并强制执行静态结构校验与本地构建校验
