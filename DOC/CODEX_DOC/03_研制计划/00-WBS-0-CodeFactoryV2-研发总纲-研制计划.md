# WBS-0 CodeFactoryV2 研发总纲

## 1. 目标

以 WBS 方式稳定组织 `CodeFactoryV2` 的研发主线、阶段边界、正式文档入口和后续实施路径。

## 2. 一级节点树

### P1 业务知识库

- 正式节点计划：`DOC/CODEX_DOC/03_研制计划/01-WBS-P1-业务知识库-研制计划.md`
- 当前职责：资料接入、结构化解析、知识抽取、治理发布、知识图谱

### P2 需求分析系统

- 正式节点计划：`DOC/CODEX_DOC/03_研制计划/02-WBS-P2-需求分析系统-研制计划.md`
- 当前职责：面向业务专家的交互式需求建模

### P3 软件设计系统

- 正式节点计划：`DOC/CODEX_DOC/03_研制计划/03-WBS-P3-软件设计系统-研制计划.md`
- 当前职责：将需求规格转化为软件设计对象与工具化描述

### P4 工具仓库

- 正式节点计划：`DOC/CODEX_DOC/03_研制计划/04-WBS-P4-工具仓库-研制计划.md`
- 当前职责：工具/组件/执行器资产管理与匹配

### P5 软件构建系统

- 正式节点计划：`DOC/CODEX_DOC/03_研制计划/05-WBS-P5-软件构建系统-研制计划.md`
- 当前职责：基于设计与工具资产装配生成目标软件

### P6 门户与平台入口

- 正式节点计划：`DOC/CODEX_DOC/03_研制计划/06-WBS-P6-门户与平台入口-研制计划.md`
- 当前职责：首页门户、导航、权限与入口承载

## 3. 节点依赖关系

- `P1` 为 `P2` 提供业务元素与知识查询能力
- `P2` 为 `P3` 提供结构化需求规格
- `P3` 为 `P4` 提供软件设计对象和工具化描述
- `P4` 为 `P5` 提供匹配后的资产与执行器
- `P6` 不改变主链顺序，但为各阶段提供统一入口
