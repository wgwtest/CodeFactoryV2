# CodeFactoryV2 设计说明目录

本目录用于沉淀 `CodeFactoryV2` 已确认、可长期追踪的正式设计说明。

当前固定采用：

- `00_总纲/`
- `P阶段_中文名/`

两层组织方式，不再使用全局顺序号平铺全部阶段文档。

## 1. 目录规则

### 1.1 `00_总纲/`

只放跨阶段、跨模块的总纲与治理文档，例如：

- 平台总体设计
- 文档治理与协同规则
- 节点合同与验收文种体系设计
- P1-P6 数据互联互通与平台交换层设计

### 1.2 `P阶段_中文名/`

只放与某个阶段直接绑定的正式设计文档。

当前阶段目录包括：

- `P1_业务知识库/`
- `P2_需求分析系统/`
- `P3_软件设计系统/`
- `P4_工具仓库/`
- `P5_软件构建系统/`
- `P6_门户与平台入口/`

### 1.3 命名规则

- 阶段主设计文档：`P阶段-中文标题.md`
- 已形成稳定 WBS 子节点的专项设计：`P阶段.子节点-中文标题.md`
- 阶段内专题设计：`P阶段-局部号-中文标题.md`

例如：

- `P5-软件构建系统设计.md`
- `P5.1-最小构建闭环设计.md`
- `P4-10-核心业务循环设计.md`
