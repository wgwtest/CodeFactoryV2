# 设计说明目录说明

`02_设计说明/` 是 `CodeFactoryV2` 的正式设计文档根。

## 1. 目录结构

- `00_总纲/`
- `P1_业务知识库/`
- `P2_需求分析系统/`
- `P3_软件设计系统/`
- `P4_工具仓库/`
- `P5_软件构建系统/`
- `P6_门户与平台入口/`

## 2. 编排规则

- 不再使用全局 `01 / 02 / 03 ...` 号位表达阶段顺序
- 总纲类文档放在 `00_总纲/`，使用普通顺序号
- 阶段主文档按 `P阶段-中文标题` 命名
- 阶段专题文档按本阶段局部编号命名，例如 `P4-10`、`P4-20`
- 与稳定 WBS 子节点一一对应的专题文档，优先直接使用 WBS 编号，例如 `P5.1`、`P6.1`
- 新增专题时，只在所属阶段目录中插入，不重排其他阶段正式文档

## 3. 使用口径

- 当前目录是正式设计入口
- `docs/superpowers/specs/` 是工作草案层
- `05_测试文档/`、`06_过程文档/` 中的旧路径文本仅作为历史证据，不作为当前正式入口
