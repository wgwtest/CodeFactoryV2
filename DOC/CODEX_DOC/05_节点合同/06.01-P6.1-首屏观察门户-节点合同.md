# `P6.1` 首屏观察门户节点合同

- 节点编码：`06.01`
- 节点名称：`P6.1` 首屏观察门户
- 节点类型：包节点合同

## 1. 工作目标

建设独立于主壳层菜单页的 `/portal` 平台门户，使其能够通过蓝图画布形式稳定呈现：

- `P1 ~ P5` 系统节点
- 参与用户节点
- 关键产物节点
- 语义连线
- 图例、知识上下文和平台摘要

## 2. 工作内容

- 建立独立路由 `/portal`
- 建立蓝图画布、节点表达、关系连线与图例区
- 建立推荐布局 / 个人布局双模式
- 建立场景切换与数据源模式展示
- 建立节点单击高亮、双击跳转与悬停联动
- 建立门户内嵌的 `P6.4` 卡片配置实验台入口

## 3. 潜在难点

- 既要保证节点与连线结构稳定，又要允许个人布局覆盖位置
- 既要允许实验台调样式，又不能破坏门户投影语义
- 既要提供足够的节点差异信息，又不能让卡片结构失控

## 7. 验收方法

- 访问 `/portal`，确认独立平台壳层可达
- 验证系统节点、参与用户节点、产物节点三类对象均可见
- 验证语义线 / 投影聚合视图切换、布局切换和场景切换可用
- 验证双击系统节点进入阶段稳定模块路由
- 验证实验台通过小型按钮进入，不额外新增主导航页面
- 对照：
  - `DOC/CODEX_DOC/06_测试文档/02_验收大纲/06.01-P6.1-首屏观察门户-验收大纲.md`
