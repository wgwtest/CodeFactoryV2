# `P6.2` 跨阶段只读集成与状态投影节点合同

- 节点编码：`06.02`
- 节点名称：`P6.2` 跨阶段只读集成与状态投影
- 节点类型：包节点合同

## 1. 工作目标

建设 `P6.2` 作为 `P6` 的读侧集成底座，使平台能够稳定获得：

- `P1 ~ P5` 阶段快照
- 门户投影
- 串行观察投影
- 新鲜度和降级原因
- 公共模拟状态源

## 2. 工作内容

- 建立 `P6.2.1` 阶段查询接口
- 建立 `P6.2.2` 状态快照模型
- 建立 `P6.2.3` 缓存与降级
- 建立 `P6.2.4` 页面接口
- 建立 `P6.2.5` 模拟状态源
- 统一形成 `/api/p6/*` 读侧接口族

## 3. 潜在难点

- 需要把阶段事实来源和平台消费契约清楚分层
- 需要保证 `mock` 和 `live` 的边界清晰，避免伪装真实源已接通
- 需要在降级可见的前提下，保持页面仍可工作
