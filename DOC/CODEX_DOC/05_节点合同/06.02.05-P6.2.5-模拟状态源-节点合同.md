# `P6.2.5` 模拟状态源节点合同

- 节点编码：`06.02.05`
- 节点名称：`P6.2.5` 模拟状态源
- 节点类型：叶子节点合同

## 1. 工作目标

在 `P1 ~ P5` 真实读源尚未稳定前，为 `P6` 提供正式的公共模拟状态源，使门户、观察页和实验页可以消费同一套场景化假数据。

## 2. 工作内容

- 定义公共场景目录
- 定义场景摘要和阶段状态模板
- 定义不同场景下的门户摘要和观察摘要差异
- 定义 `mock` 为正式首版读源的边界

## 3. 潜在难点

- 模拟数据既要统一，又要体现阶段差异
- 需要避免让 `mock` 伪装成真实数据源
- 场景切换要能同时驱动门户页、观察页和实验台

## 4. Depends On

- `DOC/CODEX_DOC/02_设计说明/P6_门户与平台入口/P6.2-跨阶段只读集成与状态投影设计.md`

- `MockScenarioSummary`
- `scenario_id`
- 阶段状态模板
- 门户与观察页场景摘要口径

- 验证不同场景会驱动不同的门户摘要和观察摘要
- 验证门户页、观察页和实验页共用同一套 `mock` 场景目录
