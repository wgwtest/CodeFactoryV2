# `P6.1.4` 门户投影模型节点合同

- 节点编码：`06.01.04`
- 节点名称：`P6.1.4` 门户投影模型
- 节点类型：叶子节点合同

## 1. 工作目标

把 `P6.2` 输出的 `PortalProjection` 收敛为 `P6.1` 可直接消费的前端视图模型，使门户页面不再以页面私有常量临时拼装：

- 节点集合
- 关系集合
- 产物集合
- 关系快照
- 门户摘要

## 2. 工作内容

- 定义门户前端视图模型与节点位置基线
- 定义 `PortalProjection` 到前端节点 / 连线 / 产物的映射
- 定义关系快照与高亮联动辅助数据
- 定义门户摘要和关系摘要的生成规则
- 定义个人布局读写与推荐布局回退规则

## 3. 潜在难点

- 投影模型既要稳定，又要兼容推荐布局与个人布局覆盖
- 视图模型不能把 API 语义和页面显示状态混在同一层
- 场景切换后摘要、节点和关系必须同步刷新

## 7. 验收方法

- 验证门户节点、关系和产物来自正式 `PortalProjection`
- 验证关系快照和门户摘要可由前端视图模型稳定生成
- 验证个人布局只覆盖位置，不覆盖门户语义对象
- 验证场景切换后门户视图模型整体刷新
