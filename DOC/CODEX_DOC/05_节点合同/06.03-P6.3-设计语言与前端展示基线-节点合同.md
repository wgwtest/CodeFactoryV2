# `P6.3` 设计语言与前端展示基线节点合同

- 节点编码：`06.03`
- 节点名称：`P6.3` 设计语言与前端展示基线
- 节点类型：叶子节点合同

## 1. 工作目标

建设 `P6.3` 作为平台统一设计语言与展示基线层，使平台能够稳定发布：

- 设计 token
- 阶段命名基线
- 状态文案与状态色基线
- 共享展示基元
- 节点视觉基线
- 改造规则与例外规则

## 2. 工作内容

- 定义 `DesignTokenSet`
- 定义 `StageNamingBaseline`
- 定义 `StatusCopyBaseline`
- 定义 `SharedDisplayPrimitive` 与 `NodeVisualBaseline`
- 定义升级规则与例外登记
- 对外发布平台展示基线、路由和图例配置

## 3. 潜在难点

- 平台统一语言不能抹平各阶段业务差异
- “无数据”和“数据暂不可用”必须从文案和色彩上明确区分
- 例外规则既要允许存在，又不能散落在实现细节里
