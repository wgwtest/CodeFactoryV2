# `P2` 需求分析系统节点合同

- 节点编码：`02`
- 节点名称：`P2` 需求分析系统
- 节点类型：包节点合同

## 1. 工作目标

建设 `P2` 作为 `P1` 发布态知识到 `P3` 软件设计对象之间的标准需求规格说明编写与冻结层，使其能够：

- 面向专业知识专家提供标准需求规格说明编写工作台
- 支持问答模式和表单模式两种同源输入
- 支持可替换规格模板、可配置表单模板、问答策略和缺口检查规则
- 消费 `P1` 已发布知识库作为可选来源引用
- 冻结后输出标准规格说明文档和结构化 `RequirementSpec`
- 保留模拟输入台作为联调入口，但不替代正式工作台

## 2. 工作内容

- 建立 `P2.1` 专家需求规格编写工作台
- 建立 `P2.2` 需求规格对象输出与投影能力
- 建立 `P2.3` 模拟输入台与联调入口
- 建立可配置需求规格说明编写系统能力
- 固化标准规格正文优先、结构化包后台支撑的产品路径
- 固化 `P2 -> P3` 的正式输入契约

## 3. 潜在难点

- 需要保持问答输入、表单输入、标准正文和结构化包同源
- 需要控制专家可轻量编辑正文，但不能破坏模板骨架和编号规则
- 需要让规格模板、表单模板、字段映射、问答策略和缺口检查规则可配置
- 需要把正文编辑无法确定同步的内容转为待确认批注，而不是静默覆盖
- 需要控制 `P2-Sim` 只承担联调入口，而不替代正式输出对象
- 需要避免需求规格编写阶段提前混入组件资产或实现细节

## 7. 验收方法

- 打开专家需求规格编写工作台，确认可选择规格模板和知识库
- 在问答模式输入内容，确认可生成或更新标准规格正文
- 在表单模式填写字段，确认可同步同一份标准规格正文
- 点击条款，确认可打开批注浮层
- 执行缺口检查，确认阻断项能够定位到章节或条款
- 冻结版本，确认生成标准文档和结构化 `RequirementSpec` 包
- 打开配置与模板管理台，确认可配置模板章节、表单字段、字段映射、问答规则和缺口检查规则
- 打开 `/xx-p2-sim`，确认模拟输入台可达
- 验证只有冻结版本能作为 `P3` 正式输入对象存在
- 验证 `P2` 输出不混入工具资产命中和运行装配语义
- 对照：
  - `DOC/CODEX_DOC/06_测试文档/01_验收大纲/02-P2-需求分析系统-验收大纲.md`
