# `P2` 需求分析系统节点合同

- 节点编码：`02`
- 节点名称：`P2` 需求分析系统
- 节点类型：包节点合同

## 1. 工作目标

建设 `P2` 作为 `P1` 发布态知识到 `P3` 软件设计对象之间的结构化翻译层，使其能够：

- 面向业务专家提供交互式需求建模入口
- 消费 `P1` 已发布知识并支持临时元素补充
- 输出结构化 `RequirementSpec`
- 形成可读投影与模拟输入台联调入口

## 2. 工作内容

- 建立 `P2.1` 应用需求建模器
- 建立 `P2.2` 需求规格对象输出与投影能力
- 建立 `P2.3` 模拟输入台与联调入口
- 固化对象优先于流程的建模路径
- 固化 `P2 -> P3` 的正式输入契约

## 3. 潜在难点

- 需要把业务语言稳定翻译为结构化对象，而不是停留在表单草稿
- 需要区分推荐项、手工项和待入库临时项
- 需要控制 `P2-Sim` 只承担联调入口，而不替代正式输出对象
- 需要避免建模阶段提前混入组件资产或实现细节
