# `P6.2.1` 阶段查询接口节点合同

- 节点编码：`06.02.01`
- 节点名称：`P6.2.1` 阶段查询接口
- 节点类型：叶子节点合同

## 1. 工作目标

为 `P6.2` 建立统一的阶段查询接口边界，使平台能够以一致方式获取：

- 模拟场景目录
- 阶段快照集合
- 门户投影
- 观察投影

并对错误场景给出明确的状态码和错误语义。

## 2. 工作内容

- 定义 `/api/p6/*` 路由入口
- 定义 `source / scenario` 参数边界
- 定义 `mock` 与 `live` 的错误映射
- 定义非法场景和非法参数的响应约束

## 3. 潜在难点

- 错误映射既要清晰，又不能让调用方猜测真实状态
- `live` 未实现时必须明确暴露未实现，而不是伪装为空数据
- 查询接口要保持统一包络，不把页面差异带入路由层

## 4. Depends On
