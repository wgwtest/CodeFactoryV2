# `P6.2.3` 缓存与降级节点合同

- 节点编码：`06.02.03`
- 节点名称：`P6.2.3` 缓存与降级
- 节点类型：叶子节点合同

## 1. 工作目标

为 `P6.2` 建立新鲜度判断、降级原因和告警摘要边界，使平台在阶段数据不完整或不可用时仍保持可观察。

## 2. 工作内容

- 定义 `fresh / stale / unknown` 新鲜度状态
- 定义 `degraded_reason` 暴露规则
- 定义观察页告警摘要与阻塞 / 告警阶段聚合
- 定义接口异常下的降级展示边界

## 3. 潜在难点

- 既要降级可见，又不能让页面整体崩溃
- “无数据”和“数据暂不可用”必须区分
- 告警摘要既要聚合，又不能吞掉具体阶段事实
