# `P6.2.2` 状态快照模型节点合同

- 节点编码：`06.02.02`
- 节点名称：`P6.2.2` 状态快照模型
- 节点类型：叶子节点合同

## 1. 工作目标

为 `P6.2` 建立统一的状态快照与节点状态负载模型，使 `P1 ~ P5` 的状态事实能被一致映射成：

- `StageSnapshot`
- `StageNodeStatusPayload`
- `StageEntryProjection`
- `StageHealthProjection`

## 2. 工作内容

- 定义阶段快照对象
- 定义门户节点状态负载对象
- 定义入口、健康、指标与时间戳字段
- 定义后端与前端类型镜像

## 3. 潜在难点

- 五阶段状态事实不同，但快照骨架必须统一
- 快照对象既要支撑门户节点，也要支撑观察页卡片
- 后端模型和前端类型需要保持镜像一致
