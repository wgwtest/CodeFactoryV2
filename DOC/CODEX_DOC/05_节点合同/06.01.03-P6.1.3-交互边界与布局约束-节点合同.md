# `P6.1.3` 交互边界与布局约束节点合同

- 节点编码：`06.01.03`
- 节点名称：`P6.1.3` 交互边界与布局约束
- 节点类型：叶子节点合同

## 1. 工作目标

为 `P6.1` 门户蓝图画布建立稳定的交互与布局边界，使门户能够支持：

- 推荐布局 / 个人布局切换
- 视口缩放与平移
- 节点拖拽与边界回收
- 页面级交互状态管理

并确保交互操作不会改写门户语义数据。

## 2. 工作内容

- 定义 `PortalLayoutProfile` 和 `PortalInteractionState`
- 定义世界坐标、视口尺寸与相机状态边界
- 定义节点拖拽的最小间距与越界回收规则
- 定义推荐布局与个人布局的覆盖关系
- 定义高亮、悬停、缩放和平移的页面级状态

## 3. 潜在难点

- 交互自由度和结构稳定性需要同时成立
- 节点拖拽既要可用，又不能把节点拖出门户主世界边界
- 相机状态、布局状态和关系视图切换之间容易相互污染
