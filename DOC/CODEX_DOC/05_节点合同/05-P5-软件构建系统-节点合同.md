# `P5` 软件构建系统节点合同

- 节点编码：`05`
- 节点名称：`P5` 软件构建系统
- 节点类型：包节点合同

## 1. 工作目标

建设 `P5` 作为 `P3` 设计结果与 `P4` 供给结果的最终装配与交付工作台，使其能够：

- 接收正式或模拟的 `P3 / P4` 输入
- 形成交付主单、输入绑定和构建尝试
- 输出版本化交付目录与结果预览
- 对缺口、反馈任务和回流建议进行结构化留痕

## 2. 工作内容

- 建立 `P5.1` 最小构建闭环
- 建立 `P5.2` 运行生成与监控规则
- 建立 `P5.3` 缺口回流与追溯规则
- 固化 `/build` 独立工作台
- 固化 `P3 / P4` 模拟输入页与 `P5` 的标准绑定关系

## 3. 潜在难点

- 需要保证 `P5` 消费的是 `P3` 冻结设计和 `P4` 已供给结果，而不是上游草稿
- 需要把交付主单、构建尝试、批阅结果和反馈任务区分为不同对象
- 需要控制带缺口导出、正式交付和回流仲裁之间的状态边界
- 需要避免把所有不兼容问题都错误归因为 `P4` 需要修旧工具
