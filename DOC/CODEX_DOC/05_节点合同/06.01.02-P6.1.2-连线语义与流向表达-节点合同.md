# `P6.1.2` 连线语义与流向表达节点合同

- 节点编码：`06.01.02`
- 节点名称：`P6.1.2` 连线语义与流向表达
- 节点类型：叶子节点合同

## 1. 工作目标

为 `P6.1` 门户蓝图画布建立稳定的连线语言，使门户中的关系表达能够明确区分：

- 主链语义流向
- 阶段间知识 / 分析 / 设计 / 工具 / 交付关系
- 锚点 / pin 起止约束
- 语义线与投影聚合两种视图

## 2. 工作内容

- 定义 `PortalFlow` 的正式字段边界
- 定义连线的 `semantic_type / render_tone / render_style`
- 定义 `from_pin / to_pin` 与锚点对齐规则
- 定义语义线视图与投影聚合视图的切换边界
- 定义产物节点与连线高亮联动规则

## 3. 潜在难点

- 连线既要表达差异，又不能让门户中心区域过度拥塞
- 缩放、拖拽和布局切换后，连线仍需保持与锚点对齐
- 展示视图切换不能被误写成关系语义切换

## 7. 验收方法

- 验证每条正式关系都声明 `semantic_type`
- 验证连线从锚点 / pin 出发，而不是从节点中心出发
- 验证语义线 / 投影聚合切换只改变展示方式，不改变底层关系事实
- 验证产物节点和相关关系可被联动高亮
