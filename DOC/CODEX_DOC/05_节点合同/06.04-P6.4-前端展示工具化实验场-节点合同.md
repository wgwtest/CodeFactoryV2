# `P6.4` 前端展示工具化实验场节点合同

- 节点编码：`06.04`
- 节点名称：`P6.4` 前端展示工具化实验场
- 节点类型：叶子节点合同

## 1. 工作目标

建设 `P6.4` 作为平台展示实验层，使平台能够以正式对象方式管理：

- 展示模板
- 字段绑定
- 布局组合
- 组合预设
- 实验记录
- 晋升候选

## 2. 工作内容

- 定义工作台引导对象
- 定义模板、绑定、布局和预设对象
- 定义实验记录与晋升候选对象
- 定义 `GET/POST /api/platform-display/*` 接口族
- 定义门户页内嵌实验台入口与保存动作

## 3. 潜在难点

- 实验层必须只消费读侧投影，不得直接绑定阶段私有状态
- 实验结果需要可记录、可对比，但不能直接改写正式阶段事实
- 实验台入口必须足够轻量，不能演变成新的主导航页面

## 7. 验收方法

- 验证 `/api/platform-display/workbench`、`/api/platform-display/experiments`、`/api/platform-display/promotion-candidates` 可访问
- 验证门户页通过小型 `卡片配置` 按钮进入实验台
- 验证 `登记实验` 会形成实验记录而不是改写阶段事实
- 验证晋升候选由实验结论派生，而不是直接人工写死到业务页面
