# `P6` 门户与平台入口节点合同

- 节点编码：`06`
- 节点名称：`P6` 门户与平台入口
- 节点类型：包节点合同

## 1. 工作目标

建设 `P6` 作为平台级门户、观察与前端展示实验层的首个正式闭环，使其能够：

- 为 `P1 ~ P5` 提供统一平台入口
- 以只读方式消费跨阶段状态投影
- 提供平台级设计语言与展示基线
- 提供前端展示实验与反哺入口

## 2. 工作内容

- 建立 `P6.1` 首屏观察门户
- 建立 `P6.2` 跨阶段只读集成与状态投影
- 建立 `P6.3` 设计语言与前端展示基线
- 建立 `P6.4` 前端展示工具化实验场
- 统一形成 `/portal` 与 `/observation` 两个平台级入口
- 在真实读源未锁定前，提供正式的 `mock` 模拟状态源

## 3. 潜在难点

- 需要保持 `P6` 对 `P1 ~ P5` 主链的解耦，不能直接回写业务阶段
- 需要区分“平台设计语言基线”和“业务页面局部样式自由度”
- 需要明确 `mock` 与 `live` 的边界，避免伪装真实源已接通
- 需要控制 `P6.4` 的实验能力不直接污染阶段正式事实

- 打开 `/portal`，确认平台门户可达
- 打开 `/observation`，确认串行观察页可达
- 验证 `P6` 只消费读侧投影，不直接承担业务写入
- 验证 `platform-config` 与 `platform-display` 路由族可用
- 验证 `P6.4` 实验结果形成记录和候选，而不直接改写阶段事实
