# WBS-P6.1 首屏观察门户研制计划

## 1. 节点目标

建设 `P6.1` 作为平台首屏观察门户，使其能够以蓝图画布方式稳定承载：

- 系统节点
- 参与用户节点
- 关键产物节点
- 语义连线
- 图例、知识上下文与平台摘要

## 2. 当前边界

`P6.1` 负责：

- 独立门户路由 `/portal`
- 门户节点与产物的图形语言
- 连线语义、流向表达与视图切换
- 布局档案、视口相机与节点交互
- 门户投影向前端视图模型的转换

不负责：

- 读侧聚合与状态归一化
- 平台统一展示基线冻结
- 实验结论的正式晋升判断
- 对 `P1 ~ P5` 的业务写回

## 4. 当前状态

- 门户页面、蓝图画布、节点表达、图例区和实验台入口已形成首版可运行闭环
- `P6.1.1` 已先行补齐节点定义合同与验收大纲
- 当前补齐重点转向：
  - `P6.1.2` 连线语义与流向表达
  - `P6.1.3` 交互边界与布局约束
  - `P6.1.4` 门户投影模型

## 5. 子节点拆解

### 5.1 `P6.1.1` 节点定义

负责系统状态卡节点、参与用户节点、产物节点和状态注记的正式显示边界。

### 5.2 `P6.1.2` 连线语义与流向表达

负责语义连线、锚点 / pin、关系视图切换和产物关联表达。

### 5.3 `P6.1.3` 交互边界与布局约束

负责推荐布局 / 个人布局、视口相机、拖拽边界和交互状态。

### 5.4 `P6.1.4` 门户投影模型

负责把 `PortalProjection` 转为前端可消费的节点、关系、产物和摘要模型。

## 6. 后续约束

- `P6.1` 只消费 `P6.2` 投影，不得直接拼装阶段私有字段
- 门户布局变化不得改变节点和关系语义
- 语义线 / 投影聚合切换只改变展示方式，不改变底层关系事实
- 门户中的实验入口必须保持小型配置按钮，不升级为主导航页面
