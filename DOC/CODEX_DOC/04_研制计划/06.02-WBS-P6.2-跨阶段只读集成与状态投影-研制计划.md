# WBS-P6.2 跨阶段只读集成与状态投影研制计划

## 1. 节点目标

建设 `P6.2` 作为平台读侧集成底座，使其能够把 `P1 ~ P5` 的阶段状态统一收敛为平台可消费的正式投影。

## 2. 当前边界

`P6.2` 负责：

- 阶段读取接口与错误映射
- 状态快照、节点状态负载和投影对象
- 新鲜度判断、降级原因与告警摘要
- 门户页、观察页和实验页的读侧分发
- 真实源未锁定前的公共模拟状态源

不负责：

- 页面渲染实现
- 平台展示 token 和命名冻结
- 展示实验流程与晋升评估
- 业务写入和命令下发

## 3. 正式设计入口

- `DOC/CODEX_DOC/02_设计说明/P6_门户与平台入口/P6-门户与平台入口设计.md`
- `DOC/CODEX_DOC/02_设计说明/P6_门户与平台入口/P6.2-跨阶段只读集成与状态投影设计.md`
- `DOC/CODEX_DOC/03_规范与流程/01_数据规范/01-P1-P5到P6状态输出接口规范.md`

## 4. 当前状态

- `mock` 模式下的阶段快照、门户投影和观察投影已形成首版接口闭环
- `live` 模式尚未接通，但已固定为明确未实现状态，不伪装真实源可用
- 当前补齐重点转向 `P6.2` 子节点的合同与验收边界

## 5. 子节点拆解

### 5.1 `P6.2.1` 阶段查询接口

负责阶段读取入口、参数边界与错误映射。

### 5.2 `P6.2.2` 状态快照模型

负责 `StageSnapshot`、节点状态负载和阶段摘要对象。

### 5.3 `P6.2.3` 缓存与降级

负责新鲜度判断、降级原因和告警摘要。

### 5.4 `P6.2.4` 页面接口

负责门户页、观察页和实验页所消费的读侧接口。

### 5.5 `P6.2.5` 模拟状态源

负责 `mock` 场景目录、场景定义与首版公共读源。

## 6. 后续约束

- `P6.2` 只能提供读侧投影，不得承担业务写链
- `mock` 是正式首版读源，不得被表述成临时脏数据
- `live` 未接通时必须显式暴露未实现状态
- 页面消费层只能读 `P6.2` 输出，不得绕过归一化对象直接消费阶段私有结构
