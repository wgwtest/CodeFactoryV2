# WBS-P3 软件设计系统研制计划

## 1. 节点目标

把 `P2` 输出的需求规格转换为结构化软件设计对象，并进一步导出冻结后的工具化描述。

## 2. 当前边界

`P3` 负责：

- 软件设计对象生成
- 软件设计说明投影
- 人工校核后的工具化描述导出

不负责：

- 需求建模本身
- 工具仓库资产持久化
- 最终软件运行装配

## 6. 后续约束

- `P3` 只消费 `P2` 的标准需求规格
- `P3` 只向 `P4` 输出冻结后的工具化描述
- 任何人工校核都必须回写结构化设计对象，再重新投影说明书和工具化描述
- `P3.2` 必须保持“需求规格说明接入与分析”独立于“软件设计说明生成与校核”
- `XX-P2-Sim` 归属 `P3.2`，作为上游联调入口处理
- `P3` 必须作为 `P5` 可行性反馈的唯一仲裁者，把反馈明确区分为设计缺口、供给缺口、装配 / 构建缺口
- 只有经 `P3` 仲裁确认的供给缺口，才能重新向 `P4` 下发新供给任务 / 派生任务 / 组件拆分任务
