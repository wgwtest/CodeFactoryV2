# W3 抽取运行模块

## 初始提示词

你接手 CodeFactoryV2 的 P1 清洁版 `抽取运行` 工作线。仓库路径是 `E:\project\Web\智能软件生成\CodeFactoryV2`。本工作线只负责 `apps/web/src/features/p1Clean/modules/runtime` 和运行态后端流，目标是消费 `archiveId + documentSetId + policyPackageVersionId`，展示实时运行、事件流、运行态语义图谱，并输出 `runtimeSnapshotId`。不要编辑策略，不要写发布候选，不要做 git commit。

## 目标

- 优先使用 stream，断线回退 polling。
- 展示当前阶段、阶段状态、事件流、运行消息。
- 图谱表达必须体现 `输入对象 -> 策略/动作依据 -> 输出对象`。
- 输出稳定 `runtimeSnapshotId` 给质量图谱和发布输出模块。

## 允许修改范围

- `apps/web/src/features/p1Clean/modules/runtime/**`
- `apps/web/src/test/*runtime*.test.ts?(x)`
- 后端优先使用或扩展：
  - `apps/api/app/archive_knowledge/runtime_service.py`
  - `apps/api/app/archive_knowledge/runtime_snapshot_service.py`
  - `apps/api/app/archive_knowledge/runtime_contract.py`
  - `apps/api/app/archive_knowledge/runtime_*`
  - `apps/api/tests/test_archive_document_runtime_api.py`
- 如需新增清洁版服务，可放在 `apps/api/app/archive_knowledge/p1_modules/runtime/**`

## 禁止改动范围

- 不编辑策略配置。
- 不做质量评分最终判定。
- 不生成发布候选。
- 不直接读取 `modules/intake` 页面状态，只消费 `documentSetId`。

## 输入合同

- `archiveId`
- `documentSetId`
- `policyPackageVersionId`

## 输出合同

- `runtimeSnapshotId`
- 运行事件流
- 当前阶段状态
- 运行态语义图谱快照

## API adapter

只能通过 `modules/runtime/api.ts` 调用：

- `getArchiveDocuments`
- `getArchiveDocumentRuntime`

新增 stream 或 runtime API 必须先进入本模块 `api.ts`。

## 验收方式

人工路径：

- 进入 `/p1/archives/:archiveId/runtime`
- 能看到当前运行上下文和运行图谱
- stream/polling 状态清晰
- 当前阶段必须来自后端状态，不允许点击伪造当前阶段

测试命令：

```powershell
cd E:\project\Web\智能软件生成\CodeFactoryV2\apps\web
npm run test -- p1CleanModuleRegistry.test.ts
npm run build
```

后端：

```powershell

.\.venv\Scripts\python.exe -m pytest apps/api/tests/test_archive_document_runtime_api.py
```
