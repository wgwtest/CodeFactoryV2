# W4 质量图谱模块

## 初始提示词

你接手 CodeFactoryV2 的 P1 清洁版 `质量图谱` 工作线。仓库路径是 `E:\project\Web\智能软件生成\CodeFactoryV2`。本工作线只负责 `apps/web/src/features/p1Clean/modules/qualityGraph` 和质量评估相关后端能力，目标是消费 `runtimeSnapshotId + policyPackageVersionId`，衡量知识概念质量、关系质量、证据覆盖、图谱可解释性和门禁解释。不要修改资料接入、策略编辑、抽取运行推进或发布输出，不要做 git commit。

## 目标

- 建立知识质量和图谱质量指标体系。
- 展示概念、关系、证据、规则命中的解释链。
- 清楚回答“为什么可信、为什么警告、为什么阻断或放行”。
- 不直接生成发布候选。

## 允许修改范围

- `apps/web/src/features/p1Clean/modules/qualityGraph/**`
- `apps/web/src/test/*quality*.test.ts?(x)`
- 后端优先使用或扩展：
  - `apps/api/app/archive_knowledge/quality/evaluator.py`
  - `apps/api/app/archive_knowledge/quality_gate_policy.py`
  - `apps/api/app/archive_knowledge/contracts/quality.py`
  - `apps/api/tests/test_archive_document_runtime_api.py`
- 如需新增清洁版服务，可放在 `apps/api/app/archive_knowledge/p1_modules/quality_graph/**`

## 禁止改动范围

- 不修改策略规则合同。
- 不直接推进抽取运行。
- 不生成发布候选。
- 不读取其它模块页面状态。

## 输入合同

- `archiveId`
- `runtimeSnapshotId`
- `policyPackageVersionId`

## 输出合同

- 质量决策摘要
- 质量指标集合
- 规则命中解释
- 图谱可解释性报告

## API adapter

只能通过 `modules/qualityGraph/api.ts` 调用：

- `getArchiveGraph`
- `getArchiveSummary`

新增质量 API 必须先进入本模块 `api.ts`。

## 验收方式

人工路径：

- 进入 `/p1/archives/:archiveId/quality`
- 能看出概念质量、关系质量、证据覆盖、图谱解释是否通过
- 能看出指标和规则如何影响门禁解释
