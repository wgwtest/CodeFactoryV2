# P1 业务知识库黄金样例交付计划

更新时间：2026-05-10

## 1. 目标

明早 7 点前优先交付一条可演示、可解释、可复现的 P1 业务知识库产出样例，而不是继续追求完整重构闭环。

样例必须让评审者能看懂：

- 用户选择一个文件夹或一组资料后，系统如何生成业务知识库。
- 系统如何识别文件夹内容主题，并推荐或绑定合适策略包。
- 策略规则如何产生候选知识、关系和证据链。
- 系统如何衡量知识质量与图谱质量。
- 发布候选与正式输出如何隔离。
- 下游系统最终消费的是正式发布知识，而不是抽取过程中的临时节点。

## 2. 黄金样例范围

样例入口：用户选择一个业务资料文件夹。

样例文件夹：`业务资料包`。

样例文件：

- `供货协议_华东区_2026Q1.pdf`
- `销售框架协议_北区_2026.docx`
- `补充协议_项目A_2026Q1.pdf`

系统识别主题：合同与履约资料。

系统推荐策略包：合同通用抽取 v3.12。

这里的“合同”不是用户预先固定选择的知识库类型，而是系统根据文件夹内容识别出的主题，并据此选择当前最合适的策略包。后续换成制度文件夹、FAQ 文件夹、项目交付文件夹时，应走同一套入口，只是推荐不同策略包。

样例知识主题：

- 合同总金额。
- 付款条件。
- 交付责任。
- 违约责任。
- 验收流程。
- 风险提示。

核心叙事：

- 用户选择文件夹后，系统建立本次资料集的知识生成任务。
- 系统识别文件类型和内容主题，推荐策略包并冻结运行快照。
- 单文档抽取生成候选知识。
- 跨文档同知识验证把重复概念归并为规范知识候选。
- 质量规则发现轻微风险，生成带警告的发布候选。
- 治理确认后才进入正式输出接口。

## 3. 演示路径

1. 进入 `/p1`，看到面向业务用户的文件夹驱动知识生成入口。
2. 选择或导入 `业务资料包`，系统展示识别主题、推荐策略包和运行快照。
3. 进入 `/documents` 或 `/archives`，查看文件夹内文档状态与抽取进度。
4. 进入单文档实时工作台，查看当前阶段、Stream 状态、策略快照和语义图谱。
5. 进入 `/p1/quality`，查看质量指标、规则命中、影响对象和数据血缘。
6. 调用 `/api/p1/knowledge-supply/read`，证明正式输出只包含已发布知识。

## 4. 明早前必须达成的质量标准

- 页面不能出现乱码、空白页、开发壳优先或明显假数据误导。
- 样例不能表现为“先选销售合同知识库”，而应表现为“先选文件夹，系统识别主题和策略”。
- 样例图谱必须表达“输入对象 -> 规则/动作依据 -> 输出对象”。
- 质量页必须清楚解释至少 3 类指标：概念质量、证据覆盖、图谱关系质量。
- 规则命中必须能追溯到 `rule_id`、`rule_version`、`rule_hash`、输入/输出产物和影响对象。
- 正式输出接口必须和发布候选区分，不能把临时候选伪装成正式知识。
